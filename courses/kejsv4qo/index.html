网络药理学全流程解析

约 1376 字大约 5 分钟

网络药理学系统生物学基本流程

2026-11-07

原文地址: 网络药理学全流程解析 | 从中药成分到核心通路：系统揭示多靶点作用机制的标准操作流程

📋 全流程实操步骤一览

① TCMSP 收成分靶点 → ② GeneCards 收疾病靶点 → ③ Venny 交集分析 → ④ STRING PPI + Cytoscape → ⑤ DAVID GO/KEGG → ⑥ 可视化(气泡图/网络图) → ⑦ 核心靶点筛选 → ⑧ 撰写机制假说

🔔 常用参数备忘：OB≥30%, DL≥0.18, STRING置信度0.4, 富集P<0.05

① 导论 · 为什么需要网络药理学？

网络药理学融合系统生物学与多向药理学，基于“成分-靶点-通路-疾病”网络，破解中药/天然产物“多成分、多靶点、多通路”的协同作用黑箱。它不仅预测核心靶点，还能系统阐述药理机制，是药物重定位和机制研究的关键技术。

🎯 目的： 发现药物作用于疾病的关键蛋白模块与生物学通路，构建可视化网络，为实验验证提供可靠假说。

⚡ 作用： 缩短研究周期，降低筛选成本，从全局角度解释药物干预疾病的分子机制。

② 成分与靶点收集

🌿 中药/成分数据库

TCMSPBATMAN-TCMETCMHERB

🔗 TCMSP: http://tcmspw.com/

🔗 BATMAN-TCM: http://bionet.ncpsb.org/batman-tcm/

1.根据研究药物（如复方、单味药）筛选活性成分，常用口服利用度（OB ≥30%）和类药性（DL ≥0.18）作为阈值。

2.从数据库获取成分对应的靶点蛋白（多为基因名/Uniprot ID）。

3.通过Uniprot (https://www.uniprot.org/) 标准化基因名称，去除非人源或重复靶点。

📦 小分子补充库

若成分未收录于中药数据库，可通过 PubChem 获取结构，导入 SwissTargetPrediction 或 PharmMapper 反向预测靶点。

🔗 PubChem: https://pubchem.ncbi.nlm.nih.gov/ 🔗 SwissTargetPrediction: http://www.swisstargetprediction.ch/

实操步骤： 检索化学成分 → 按ADME参数筛选 → 提取靶点 → 合并去重 → 基因名标准化 → 保存为Excel/CSV

③ 疾病靶点收集

🧬 主要疾病数据库

GeneCards OMIM DisGeNET TTD PharmGKB

🔗 GeneCards: https://www.genecards.org/

🔗 OMIM: https://omim.org/

🔗 DisGeNET: https://www.disgenet.org/

1.以疾病关键词（如“Alzheimer’s disease”）检索，收集相关性得分高的靶点。

2.推荐设置阈值：GeneCards中取 Relevance score > 中位数 或 前30%；DisGeNET 取 score ≥ 0.1 或 证据等级高的靶点。

3.整合多个数据库，去除冗余，同样用Uniprot校正为官方基因名。

📌 技巧 可同时检索GAD、CTD等，获得更全面的疾病基因集。

④ 交集靶点 · 药物-疾病共同靶点

🔄 韦恩图工具

🔗 Venny 2.1: https://bioinfogp.cnb.csic.es/tools/venny/

🔗 jvenn: http://jvenn.toulouse.inra.fr/

将成分靶点列表和疾病靶点列表上传，自动生成交集靶点及韦恩图。

📊 R语言 / Python

使用 VennDiagram 包或 pandas 的集合运算，适合批量处理多组数据，同时输出交集基因表。

作用： 交集靶点即为药物可能调控疾病的核心靶点池，后续分析均围绕此集合展开。

⑤ PPI网络构建与核心靶点筛选

PPI 网络数据

🔗 STRING 数据库 https://string-db.org/

1.导入交集靶点基因列表，物种选择“Homo sapiens”。

2.设置最小相互作用阈值：默认中等置信度 0.4（可提高到0.7获得更可靠网络）。

3.隐藏游离节点，导出TSV格式（包含node1, node2, combined_score）。

📈 Cytoscape 可视化

1.将STRING的TSV文件导入Cytoscape (https://cytoscape.org/)。

2.使用 NetworkAnalyzer 计算拓扑参数：度值、介数、紧密度。

3.通常选取度值排名前10-30的基因作为核心靶点（hub genes）。

可选工具：Gephi、或STRING内置分析导出图片。

⑥ GO 与 KEGG 富集分析

🧪 DAVID (完全免费)

🔗 https://david.ncifcrf.gov/

1.上传交集靶点列表，选择OFFICIAL_GENE_SYMBOL，物种为人类。分别勾选GOTERM_BP/CC/MF 与 KEGG_PATHWAY。

2.输出结果包含P值、富集倍数、基因数。常用筛选标准：P<0.05，Count≥3。

⚡ Metascape (限量免费)

🔗 https://metascape.org/

一键式富集分析，提供条形图、气泡图及网络可视化，自动聚类功能强大。适合初学者。

📊 R语言 · clusterProfiler (完全免费)

更灵活的可视化（气泡图、通路弦图、cnetplot）。支持自定义背景基因集，适合已熟悉R的用户。

结果解读： GO分析揭示靶点参与的生物学过程（BP）、细胞组分（CC）、分子功能（MF）；KEGG通路显示主要富集的信号通路，如PI3K-Akt、MAPK、TNF等，这些通路往往与疾病机制紧密相关。

⑦ 应用 & 目的 & 作用 & 最终结果

🔬 应用场景

  • 中药复方/单药作用机制预测

  • 药物重定位（老药新用）

  • 活性成分筛选及组合优化

  • 毒理学/不良反应机制解析

🎯 目的与作用

  • 系统揭示“多成分-多靶点”协同机制

  • 缩小实验验证范围，提高命中率

  • 构建“成分-靶点-通路”多维网络

  • 为精准医学及组合药物设计提供线索

✅ 最终结果

  • 1.核心靶点（hub genes）列表及PPI拓扑图

  • 2.显著富集的GO term 和 KEGG通路（附气泡图/条形图）

  • 3.成分-靶点-通路 整合网络（C-T-P网络）

  • 4.一份包含机制假说的报告，用于后续分子生物学验证（如qPCR、Western Blot、分子对接）
