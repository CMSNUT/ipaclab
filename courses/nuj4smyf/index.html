WSL2Ubantu的安装配置总结

约 1638 字大约 5 分钟

2026-11-04

系统环境：浪潮双路至强服务器 | 96GB 内存 | C盘/D盘固态，E盘 5TB 机械

最终目标：Windows Server 2022 + WSL2 + 原生编译 R 4.6.2 + RStudio Server + Tailscale 穿透

1. Windows Server 2022 基础系统安装

  • 启动盘制作：使用 Rufus，必须选 GPT + UEFI 模式写入。
  • BIOS 设置：浪潮服务器开机按 DEL 进 BIOS，按 F11 进 Boot Menu。
  • ⚠️ 坑 1：开机卡在 RAID 卡自检。屏幕显示 BIOS Installed Successfully! 后卡死。不要慌，按 Ctrl+A 或 End 尝试跳过。如果彻底死机，需要断电排查硬盘或重新插拔 SAS 线。
  • ⚠️ 坑 2：安装时报错 0x8000ffff。这是系统更新服务卡住了。在安装界面按 Shift+F10 呼出 CMD，执行：
    net stop wuauserv
net stop cryptsvc
ren C:\Windows\SoftwareDistribution SoftwareDistribution.old
  • 桌面配置：装完后桌面只有一个回收站。右键桌面 -> 个性化 -> 主题 -> 桌面图标设置，把“计算机”等勾选出来。

2. WSL2 的安装与底层配置

  • 开启底层功能（管理员 PowerShell）：

    dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart

    （注意：不需要开启完整的 Hyper-V，这是很多人犯的错，全开会导致 VMware 等冲突）。 执行完必须重启。

  • 安装内核：去微软官网下载 wsl_update_x64.msi 并安装。

  • ⚠️ 坑 3：镜像网络模式的致命冲突。在 C:\Users\Administrator\.wslconfig 中，千万不要加 networkingMode=mirrored。这个模式会导致 WSL 里的 Tailscale 路由崩溃，导致外部死活连不上 8787 端口。

    [wsl2]
memory=80GB
processors=48
swap=16GB

3. Ubuntu 的离线安装与权限打通

  • ⚠️ 坑 4：微软商店超时 / wsl --install 超时。千万不要死磕命令行。
    • 直接去 https://aka.ms/wslubuntu2204 下载 .AppxBundle 包。
    • ⚠️ 坑 5：报错 0x80073CF3 (缺少 VCLibs 框架)。先在 PowerShell 运行 Add-AppxPackage -Path "https://aka.ms/Microsoft.VCLibs.x64.14.00.Desktop.appx" 补齐依赖，然后再执行 Add-AppxPackage .\Ubuntu2204-*.AppxBundle。
  • ⚠️ 坑 6：跨盘符没有写入权限。Ubuntu 装好后，发现无法往 /mnt/e (E盘) 写文件。
    • 打开 /etc/wsl.conf（没有就新建），加入以下代码，然后 wsl --shutdown 重启：
    [automount]
options = "metadata,umask=22,fmask=11"

4. Miniconda 安装

  • 下载：wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
  • 安装：bash Miniconda3-latest-Linux-x86_64.sh（一路 Enter 和 yes）。
  • ⚠️ 坑 7：安装完命令找不到。执行 source ~/.bashrc 刷新环境变量。顺手把安装包 .sh 删了。

5. R 与 RStudio Server（全篇最硬核、坑最多）

  • 依赖安装（必须全装，否则 configure 报错）：
    sudo apt update
sudo apt install -y build-essential gfortran libreadline-dev libx11-dev libxt-dev libpng-dev libjpeg-dev libcairo2-dev libbz2-dev liblzma-dev libpcre2-dev libcurl4-openssl-dev libglpk-dev texinfo texlive texlive-fonts-extra
  • 下载 R 4.6.2 源码并解压：tar -xzvf R-4.6.2.tar.gz。
  • ⚠️ 坑 8：make 报错找不到 Makefile。因为你没运行 ./configure。
  • 配置安装到 /opt：
    ./configure --prefix=/opt/R/4.6.2 --enable-R-shlib --with-blas --with-lapack
  • ⚠️ 坑 9：configure: error: --with-x=yes (default) and X11 headers/libs are not available。如果上面那一长串依赖没装全，或者只想纯命令行跑，加参数：./configure --prefix=/opt/R/4.6.2 --enable-R-shlib --with-x=no。
  • 编译与安装：
    make -j$(nproc)
sudo make install
  • ⚠️ 坑 10：普通用户无法装 R 包。因为 sudo make install 后目录归 root 所有。必须把权限下放：
    sudo chown -R aikemi:aikemi /opt/R/4.6.2
  • 安装 RStudio Server：sudo apt install ./rstudio-server-*.deb。
  • ⚠️ 坑 11：RStudio 执意使用系统老版本 R 4.1.2。修改 /etc/rstudio/rserver.conf，强行指定：
    rsession-which-r=/opt/R/4.6.2/bin/R
  • ⚠️ 坑 12：网页登录报错 Incorrect or invalid username/password。这是 WSL 下 PAM 认证模块的锅。执行：
    sudo cp /etc/pam.d/login /etc/pam.d/rstudio
sudo systemctl restart rstudio-server
  • ⚠️ 坑 13：日志报错 Unable to write to log file。这是 RStudio 找不到家目录的隐藏文件夹。执行：
    mkdir -p ~/.local/share/rstudio/log ~/.local/share/rstudio/monitored
sudo chown -R aikemi:aikemi ~/.local
  • 配置工作目录：修改 /etc/rstudio/rsession.conf，将其指向 E 盘：
    session-default-working-dir=/mnt/e/projects
session-default-new-project-dir=/mnt/e/projects

6. Tailscale 的安装与网络穿透

  • 安装：在 Ubuntu 内部执行 curl -fsSL https://tailscale.com/install.sh | sh，然后 sudo tailscale up 登录。

  • ⚠️ 坑 14：外部电脑死活连不上 http://100.x.x.x:8787。

    • 第一步：在 Windows 宿主机的 管理员 PowerShell 中，必须强行放行防火墙：
      New-NetFirewallRule -DisplayName "WSL Allow All" -Direction Inbound -InterfaceAlias "vEthernet (WSL)" -Action Allow
New-NetFirewallRule -DisplayName "Allow RStudio 8787" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 8787 -Profile Any
    • 第二步：如果还是超时，千万不要死磕。直接使用 SSH 隧道终极方案。

7. 远程开发配置（VS Code 与 RStudio）

方案 A：VS Code 远程 (适合写复杂代码、工程)

  1. 本地 Windows 安装 VS Code。

  2. 安装插件 Remote - SSH 和 R。

  3. Ubuntu 内安装 SSH 服务：sudo apt install openssh-server && sudo service ssh start。

  4. 在 VS Code 中按 F1，输入 Remote-SSH: Connect to Host，输入 ssh aikemi@100.x.x.x 连接，即可丝滑敲代码。

在 VS Code 连接上 SSH 后，如果界面是空的：

  1. 点击左上角的 文件 (File) -> 打开文件夹 (Open Folder)。
  2. 此时顶部会弹出一个路径输入框。
  3. 直接输入：/mnt/e/projects，然后回车。
  4. 它就会加载你的项目目录，并在左侧资源管理器（Explorer）里显示出来。
  5. 下次你再连 SSH 的时候，它通常会自动恢复你上一次打开的这个文件夹。

方案 B：RStudio Server 网页版 (适合数据探索、画图)

  • 直连：浏览器访问 http://100.x.x.x:8787。
  • ⚠️ 坑 15：如果直连超时，用 SSH 隧道保底。 在你的本地电脑（非服务器）打开 PowerShell，输入：
    ssh -L 8787:127.0.0.1:8787 aikemi@100.x.x.x
    输入密码后，黑窗口不要关，浏览器打开 http://localhost:8787，完美解决任何防火墙问题。

8. 补充：Git 与 Docker

Git 安装与配置

  • sudo apt install git
  • 配置账号：git config --global user.name "aikemi" 和 git config --global user.email "邮箱"。
  • 生成密钥：ssh-keygen -t ed25519 -C "邮箱"，把公钥贴到 GitHub。

Docker 安装与避坑

  • 在 Ubuntu 中用官方脚本安装。
  • ⚠️ 坑 16：WSL 重启后 Docker 服务不自动启动。把启动命令写进 ~/.bashrc：
    if ! service docker status > /dev/null 2>&1; then sudo service docker start > /dev/null 2>&1; fi
  • ⚠️ 坑 17：每次敲 docker 都要 sudo。执行 sudo usermod -aG docker $USER，然后必须 wsl --shutdown 彻底重启才生效。

9. 网络加速（国内环境必须配置）

  • APT 换源：修改 /etc/apt/sources.list 为清华源。
  • Conda 换源：修改 ~/.condarc。
  • R 换源：在 RStudio 控制台执行 options(repos = c(CRAN = "https://mirrors.tuna.tsinghua.edu.cn/CRAN/"))。

10. 系统维护与清理

  • 清理 Apt 缓存：sudo apt clean，sudo apt autoremove --purge。
  • ⚠️ 坑 18：Waiting for cache lock (系统在后台自动更新)。找到进程号，sudo kill -9 <PID> 强杀，然后 sudo dpkg --configure -a 修复。
  • 释放 WSL 空间：在 Windows 下执行 diskpart，select vdisk file="C:\...\ext4.vhdx"，然后 compact vdisk 压缩虚拟磁盘。
