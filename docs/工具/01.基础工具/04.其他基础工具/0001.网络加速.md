## 一、Watt Toolkit

**Watt Toolkit**(原名 Steam++)是一款开源跨平台的多功能工具箱，其网络加速功能通过 **本地反向代理** 技术实现，并非传统 VPN 或全局代理，专门用于优化 Steam 社区、GitHub、Hugging Face、谷歌翻译等国内访问不稳定的网站和服务的连接速度。软件基于 GPL v3 协议开源，完全免费，无需登录即可使用大部分功能。



## 二、下载与安装

### 2.1 确认系统要求

在下载前，请先确认设备满足以下最低系统要求：

| 操作系统 | 最低版本要求 |
|---|---|
| Windows | Windows 10 版本 1809(OS 内部版本 17763)或更高 / Windows 11 |
| macOS | 10.15 或更高版本 |
| Linux | Ubuntu 20.04+ / Debian 11+ / Fedora 37+ / Deepin(UOS) 20+ |
| Android | 5.0(API 21)或更高版本 |

### 2.2 选择官方下载渠道

请务必从以下官方渠道获取安装包，避免从非正规来源下载带来的安全风险：

| 渠道 | 说明 | 推荐场景 |
|---|---|---|
| **软件官网** | [steampp.net](https://steampp.net) | 追求最新功能，直接下载桌面版 |
| **GitHub Releases** | [github.com/BeyondDimension/SteamTools/releases](https://github.com/BeyondDimension/SteamTools/releases) | 开源用户、需要查看源代码 |
| **Microsoft Store** | 商店搜索 “Watt Toolkit” | 希望自动更新、省心维护 |
| **Steam 商店** | Steam 商店搜索 | Steam 用户便捷获取 |
| **Gitee(码云)发行版** | Gitee Releases | GitHub 访问受限时的替代渠道 |
| **AUR(Arch Linux)** | `watt-toolkit-bin`(稳定版) / `watt-toolkit-git`(源码构建版) | Arch Linux 用户 |

>[!notes] Microsoft Store 版本因审核流程，更新通常比官网桌面版晚几天。如追求最新功能，建议选择官网桌面版; 如希望自动更新省心，可选择 Microsoft Store 版本。

### 2.3 根据平台选择安装包

下载页面中提供多个文件，命名规则为「名称\_版本号\_平台\_架构.扩展名」，按平台选择对应版本：

- **Windows**：`.msix`(商店安装包)或 `.7z`(免安装压缩包)，根据 CPU 架构选择 x64 / x86 / Arm64
- **macOS**：`.pkg` 或 `.dmg`，根据芯片选择 Intel 或 Apple Silicon 版本
- **Linux**：`.deb`(Debian/Ubuntu)、`.rpm`(Fedora)或通用压缩包
- **Android**：`.apk`

### 2.4 安装步骤

**Windows：**
1. 下载对应架构的 `.msix` 或 `.7z` 文件。
2. 若下载 `.7z` 压缩包，解压后直接运行 `Steam++.exe` 即可。
3. 若下载 `.msix`，双击安装，系统会自动完成部署。
4. **以管理员身份运行**：右键程序图标，选择“以管理员身份运行”，避免权限不足导致加速失败。
5. 如杀毒软件(360、Windows Defender 等)误报，需手动添加信任或暂时关闭实时监控。

**macOS：**
1. 下载 `.pkg` 或 `.dmg` 文件，双击按提示完成安装。
2. 首次运行时，系统可能提示需要在“安全性与隐私”中允许来自该开发者的应用。
3. 加速功能需要写入 hosts 文件和安装证书，按软件内提示操作即可。

**Linux：**
1. Debian/Ubuntu 用户下载 `.deb` 包，执行 `sudo dpkg -i 包名.deb` 安装。
2. Fedora 用户下载 `.rpm` 包，执行 `sudo rpm -ivh 包名.rpm` 安装。
3. Arch 用户可通过 AUR 安装 `watt-toolkit-bin`。
4. 首次启动可能需要授予 hosts 文件写入权限。


## 三、网络加速配置

### 3.1 启动软件并进入加速模块

1. 双击运行 Watt Toolkit(Windows 上可执行文件可能仍显示为 `Steam++.exe`)。
2. 在主界面左侧导航栏中，点击 **“网络加速”**，这是加速功能的核心入口。

### 3.2 选择需要加速的服务

在“网络加速”页面中，找到“平台加速”列表，根据需求勾选对应的复选框：

- **游戏平台**：Steam、Epic、Origin、Uplay、暴雪战网等
- **开发工具**：GitHub(建议勾选所有 GitHub 相关服务，如 GitHub、GitHub Api、GitHub Assets)、Hugging Face
- **谷歌服务**：Google 翻译(如需加速其他谷歌服务如搜索、Gmail，需通过“新增规则”自定义域名)
- **其他**：Twitch、谷歌验证码等

> **注意**：部分版本可能将 Hugging Face 归为 “Beta” 类，需确认勾选 “Beta” 选项下的对应条目。

### 3.3 安装证书(推荐)

为避免加速后浏览器出现 SSL 证书错误(如“无法验证服务器身份”)，建议先安装证书：

1. 在“加速设置”中找到 **“安装证书”** 选项。
2. 按照提示完成证书安装(Windows 会弹出证书导入向导，macOS/Linux 可能需要在终端中输入密码信任证书)。

### 3.4 启动加速

勾选完所需服务后，点击页面顶部的 **“一键加速”** 按钮。Watt Toolkit 会自动配置代理规则，将选定服务的网络请求重定向至加速节点。等待界面提示 **“加速成功”** 即可。


## 四、验证加速效果

加速启动后，可通过以下方式验证是否生效：

1. **浏览器访问**：打开浏览器访问目标网站，例如：
   - Hugging Face：`https://huggingface.co`，检查模型库、数据集页面能否正常加载。
   - Google 翻译：`https://translate.google.com`，检查页面能否正常打开且翻译功能可用。
   - GitHub：访问任意仓库页面，检查图片、脚本能否正常加载。

2. **速度对比**：在加速前后分别访问同一网站，对比页面加载速度是否有明显提升。

3. **DNS 测试**：在“网络加速”页面中找到 **“网络测试 → DNS 测试”**，验证当前使用的 DOH/DNS 地址是否可用。


## 五、常见问题排查

### 5.1 加速服务启动失败(端口被占用)

若提示“加速服务启动失败，443 端口被占用”(常见于安装了 VisualSVN Server 的情况)：

- **方法一**：打开任务管理器，找到占用端口的进程(如 `svnhttpsvc`)，结束该进程。
- **方法二**：在“加速设置”中将加速模式从默认模式切换为 **PAC** 或 **System** 模式。

### 5.2 加速后网站仍无法访问

- **切换代理模式**：进入“加速设置”，尝试在 “Hosts”“PAC”“System” 等模式之间切换。
- **切换 DOH/DNS**：在“加速设置 → 代理设置”中切换可用的 DOH 或 DNS 地址，然后重新开启加速。可在“DNS 测试”中验证新地址是否可用。
- **关闭冲突软件**：暂时关闭杀毒软件或防火墙的实时监控，部分安全软件可能拦截 Watt Toolkit 的代理服务。
- **更新软件**：确保使用最新版本，旧版本可能存在兼容性问题。

### 5.3 加速后程序异常闪退，无法上网

这是因为程序在启用加速后非正常退出，导致加速修改的网络配置未被还原。修复步骤：

1. 检查 `C:\Windows\System32\drivers\etc\hosts` 文件是否已还原。
2. 打开“设置 → 网络和 Internet → 代理”，确认“使用代理服务器”开关已关闭。
3. 以管理员身份打开命令提示符，执行 `netsh winsock reset`，然后重启电脑。

也可使用 2.5.0 以上版本中“加速设置”内的 **“网络修复”** 功能一键恢复。

### 5.4 操作 hosts 文件提示权限不足

- 先排查是否是杀毒软件拦截导致。
- 如仍无法访问，可尝试删除 hosts 文件后重新开启加速，程序会自动重新创建有权限的 hosts 文件。

### 5.5 下载模型速度慢(Hugging Face 场景)

- 在“加速设置”中切换加速节点(如选择“中国香港”或“新加坡”节点)。
- 使用 `huggingface-cli download` 命令时添加 `--resume-download` 参数以支持断点续传。


## 六、附加功能简介

除网络加速外，Watt Toolkit 还集成了以下实用工具，可在左侧导航栏对应模块中使用：

- **账号切换**：快速切换 Steam、Epic、Uplay 等多平台已登录账号
- **库存管理**：管理 Steam 游戏库存，编辑游戏名称和封面，监控下载进度并定时关机
- **本地令牌**：统一保存 Steam、Google 等平台的手机令牌，支持批量确认交易
- **自动挂卡**：模拟运行 Steam 游戏，挂取游玩时间和掉落卡片
- **游戏工具**：强制游戏窗口使用无边框窗口化等


## 七、注意事项

- **加速原理**：Watt Toolkit 通过本地反向代理探测并选择最优 IP 节点，不改变全局网络设置，关闭加速后网络即恢复正常。
- **保持更新**：建议保持软件为最新版本，以获取最佳兼容性和节点质量。
- **数据备份**：覆盖升级时注意备份旧版本重要数据(如本地令牌)，旧脚本可在 `AppData\Plugins\Accelerator\Scripts` 中找回。
- **合规使用**：请遵守当地法律法规及目标网站的服务条款，仅将工具用于合法合规的网络访问需求。
