### ⚙️ 第二步 — EM → NVT → NPT →生产



```
conda activate mdanalysis
python 2_AutomateGromacs.py
```

典型流量：

- 使用电磁安全设置进行能量最小化
- NVT平衡配合GPU加速（如有）提供
- NPT均衡配合GPU加速（如可用）
- 带GPU加速的生产型MD（如有）
- 如果检测到无可用显卡，CPU后备
- 交互式选择时长或通过CLI参数

对于中断的生产运行，请使用上述检查点安全重启命令。

### 📊 第3A步——分析



```
conda activate mdanalysis
python 3A_AutomateGromacs.py
```

典型提示：

```text
Detected ligand candidate: A1D
Use A1D as ligand? [Y/n]: Y
Enter compound display name (or press ENTER to use resname): CPD32
Detected 24 CPU threads available
Enter number of threads to use [ENTER = auto]:
```

重要的分析模式行为：

- 如果你在 中选择 **PROTAC**，脚本会自动切换到`3A_AutomateGromacs.py``3_PROTAC_Analysis.py`
- 如果你做**配体**分析并且存在，可以自动调用它来构建配体相互作用网络图`3B_NETWORX.py``3A_AutomateGromacs.py`
- 如果你运行**无配体多链蛋白-蛋白/蛋白-肽**分析，则 除非使用`3A_AutomateGromacs.py``3C_Interface_RIN.py``--skip-interface-rin`
- 如果**运行蛋白-肽模式而不使用显性配体**，则被视为界面分析，而非配体式的NETWRX
- 如果你明确地提供，3A保持配体中心的行为`--ligand`
- 如果运行**单链蛋白**分析或**生物系统**分析，则跳过配体式NETWRX和界面RIN调度

### 📄 第四步 — PDF图书



```
conda activate mdanalysis
python 4PDF4MD.py
```

对于标准配体/蛋白质/肽/生物任务，图形排序由以下控制：

```text
4_MDfigs.txt
```

可为单个手办提供可选定制笔记：

```text
4_GraphNotes.txt
```

对于PROTAC作业，自动检测生成的清单：`4PDF4MD.py`

```text
Analysis_Results/PROTAC/QC/protac_figure_manifest.csv
```

在这种情况下，PDF 构建器使用清单而不是 。`4_MDfigs.txt`
