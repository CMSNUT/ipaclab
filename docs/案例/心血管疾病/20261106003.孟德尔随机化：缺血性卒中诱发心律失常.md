::: tip 文献导读
缺血性卒中危害严重，常引发心脏并发症，但因果关系不明。本研究采用两样本孟德尔随机化，利用 GWAS 数据证实，缺血性卒中可因果致心律失常等心脏并发症。2 型糖尿病、高胆固醇血症等代谢病是潜在介导因素，PDE3A 基因与 cAMP 通路为共同遗传机制。
::: 

## 研究亮点

- 明确因果关系：通过严谨的 MR 分析，首次在遗传层面证实缺血性卒中与心律失常（尤其是房颤和室性心律失常）存在因果关联。

- 揭示介导通路：发现糖尿病相关并发症（尤其是微血管和大血管病变）是缺血性卒中诱发心律失常的关键介导因素，为机制研究提供了新方向。

- 定位核心基因：鉴定出 PDE3A 基因（rs11045239）是缺血性卒中与心律失常的共享因果变异，并证实其通过 cAMP 信号通路发挥作用。

- 临床转化价值：在房颤患者中验证了 PDE3A 基因的显著上调，为 SHS 的预测、风险分层及靶向治疗提供了潜在生物标志物和干预靶点。

::: details 摘要
引言： 中风-心脏综合征（SHS）的临床表现强调了中枢神经系统与心血管系统的相互作用。虽然心律失常是SHS患者心脏损伤的主要形式，但缺血性卒中与心律失常之间的因果关系仍不明确。

方法： 使用孟德尔随机分析和全基因组关联研究数据，`探讨缺血性卒中对心脏并发症的因果作用`。采用介导和共定位分析以识别潜在通路和共享的遗传变异。与心律失常和缺血性卒中相关的单核苷酸多态性（SNP）被用于基因本体论和京都基因与基因组百科全书（KEGG）分析。用于验证的参考是房颤患者的基因表达综合数据库（GEO）。

结果： 孟德尔随机分析显示，心律失常（包括室性心动过速）与缺血性中风之间存在强烈相关性。糖尿病微血管（肾病、视网膜病变）和宏大血管（心肌病、周围动脉疾病）并发症显著介导缺血性中风对心律失常和心房颤动的影响，分别解释了间接效应的28.69%和20.48%。共定位分析发现磷酸二酯酶3A（PDE3A）基因（rs11045239）存在共同因果变异，为缺血性卒中与心律失常之间存在共同致病途径提供了遗传证据。此外，KEGG通路富集分析发现环腺苷单磷酸（cAMP）信号通路在缺血性卒中和心律失常中的作用。使用GEO数据库验证，房颤患者PDE3A基因表达显著上调。

结论： 本研究证明缺血性中风与心律失常之间存在因果关系，糖尿病并发症是其中一个介导因素。识别PDE3A基因中的共同因果变异及cAMP信号通路的作用，有望改善SHS患者的预测和管理。

关键词： 心律失常;糖尿病并发症;缺血性中风;孟德尔随机化;PDE3A基因。
:::

## 研究背景

中风 - 心脏综合征（SHS）中，`心律失常是最常见的心脏损伤表现`，`显著增加缺血性卒中患者死亡率`，但`两者间的因果关系及机制尚不明确`。


## 研究方法
::: 技术方案
- 1.因果推断：采用两样本孟德尔随机化（MR）分析，利用全基因组关联研究（GWAS）数据，评估缺血性卒中与心律失常（包括房颤、室性心律失常）及其他心脏并发症的因果关联。

- 2.机制解析：通过介导分析，探究糖尿病微血管 / 大血管并发症、高胆固醇血症及脂蛋白代谢障碍等因素在缺血性卒中致心律失常中的介导作用。

- 3.遗传共定位：采用遗传共定位分析，识别缺血性卒中与心律失常共享的因果遗传变异及关键基因。

- 4.通路与验证：对关键基因进行 GO/KEGG 通路富集分析，并利用 GEO 数据库中房颤患者的转录组数据验证关键基因的表达变化。
:::
