| 平台 | 访问链接 | 特点 |
|---|---|---|
| **Kaggle** | https://www.kaggle.com/datasets | 数据集丰富，竞赛驱动，社区活跃 |
| **Zenodo** | https://zenodo.org | 学术数据存储，DOI可引用，开放获取 |
| **Figshare** | https://figshare.com | 多学科数据共享，支持多种格式 |
| **UCI ML Repository** | https://archive.ics.uci.edu/ml | 经典机器学习数据集，历史悠久 |
| **Lovelace's Square** | https://lovelacesquare.org | 化学计量学专用社区，数据+算法+工具 |
| **Hugging Face** | https://huggingface.co/datasets | 新兴数据集托管平台，NLP和科学数据兼有 |
| **IEEE DataPort** | https://ieee-dataport.org | 遥感与高光谱数据集 |
| **MoleculeNet** | https://moleculenet.org | 分子机器学习基准数据集集合 |
| **OQMD** | http://oqmd.org | 开放量子材料数据库 |
| **NOMAD** | https://nomad-lab.eu | 综合性材料数据仓库 |
