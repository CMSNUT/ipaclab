## 分类速查

| 大类 | 分析原理 | 代表仪器 |
|---|---|---|
| 分子光谱 | 分子对光的吸收 / 发射 / 散射 | 紫外可见、红外、拉曼、荧光 |
| 原子光谱 | 原子外层电子跃迁 | 原子吸收 AAS、原子荧光 AFS、ICP-OES |
| 色谱质谱 | 组分在固定相与流动相间分配差异 | GC、HPLC、IC、GPC、CE、GC-MS、LC-MS |
| 波谱共振 | 原子核 / 电子自旋共振 | NMR、EPR/ESR |
| 电化学 | 电极电位 / 电流响应 | pH 计、电导率仪、电位滴定、伏安 |
| 热分析 | 温度变化下的质量 / 热量 / 形变 | TGA、DSC、DTA、TMA、DMA |
| 表面与形貌 | 电子 / 光子与表面相互作用 | SEM、TEM、AFM、XPS、BET |
| 元素与同位素 | 元素含量 / 同位素比值 | 元素分析仪、ICP-OES/MS、AAS、XRF |
| 物理性能力学 | 物理量 / 力学量直接测量 | 万能试验机、硬度计、粘度计、粒度仪 |
| 生命科学生物 | 生物分子识别与扩增 | PCR、流式、酶标仪、测序仪 |
| 样品前处理 | 消解 / 萃取 / 浓缩 / 研磨 | 微波消解、固相萃取、旋转蒸发、冻干机 |
| 实验室通用辅助 | 实验室基础保障 | 天平、烘箱、马弗炉、纯水机、安全柜 |
