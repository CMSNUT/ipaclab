### 📦 `spectra-all-in-one` 包清单（Python 3.11）

#### 一、核心科学计算依赖（所有分析的基础）

| 包名 | 用途 | 安装方式 | 版本 / 兼容性说明 |
| :--- | :--- | :--- | :--- |
| **numpy** | 数值数组运算，所有光谱数据的底层结构 | **pip** | 基础必备 |
| **scipy** | 信号处理（平滑、求导、峰值检测）、插值、优化 | **pip** | 基础必备 |
| **pandas** | 光谱元数据与结果表格管理 | **pip** | 基础必备 |
| **matplotlib** | 光谱曲线、等高线图、二维谱图可视化 | **pip** | 基础必备 |
| **scikit-learn** | PCA/PLS 底层、分类/回归/聚类通用机器学习接口 | **pip** | 基础必备 |

> 这 5 个包是后续所有专用包的依赖基础，**必须先装**，避免后续包在解析依赖时反复拉扯版本。


#### 二、通用光谱预处理与化学计量学

| 包名 | 用途 | 安装方式 | Python 3.11 兼容性 |
| :--- | :--- | :--- | :--- |
| **pybaselines** | 基线校正算法库（ALS、arPLS、airPLS 等），适用于荧光、拉曼、LIBS 等多种光谱的背景扣除 | **pip** | 要求 **Python ≥3.9**，3.11 完全兼容 |
| **rampy** | 通用光谱预处理（基线扣除、平滑、重采样、峰面积），支持 Raman / IR / XAS | **pip** | 最低 **Python ≥3.10**，3.11 兼容 |
| **spectrapepper** | 光谱预处理与组合分析（降维、机器学习集成） | **pip** | Python 3 兼容，分类器包含 3.10 但无上限限制 |
| **pyChemometrics** | 化学计量学对象封装（ChemometricsPCA / PLS / PLS-DA），补充 sklearn 缺失的 DmodX 等诊断指标 | **pip** | piwheels 已有 **Bookworm Python 3.11** 构建 |

### ⚙️ 统一安装命令（pip 优先）

```bash
# 1. 创建环境，明确指定 Python 3.11
conda create -n spectra-all-in-one python=3.11 -y
conda activate spectra-all-in-one
pip install --upgrade pip

# 2. 核心科学计算依赖（先装，作为底座）
pip install numpy scipy pandas matplotlib scikit-learn

# 3. 通用预处理与化学计量学
pip install pybaselines rampy spectrapepper pyChemometrics

# 4. 各光谱类型专属工具
pip install libssa libssa-gui ramanspy matchms nmrglue pyMCR spectrochempy SpectraFit

# 5. Jupyter 内核
pip install ipykernel
python -m ipykernel install --user --name spectra-all-in-one --display-name "Python (spectra-all-in-one)"
```


### ⚠️ 需要留意的两处

**① `matchms` 的 RDKit 依赖**
`matchms` 0.33.1 已经将 RDKit 作为常规依赖，pip 安装时应自动处理。如果 pip 在解析 RDKit 二进制 wheel 时遇到问题，**不要硬扛**，回退到 conda 安装 `matchms`（conda-forge + bioconda 频道），其余包仍用 pip，不会破坏环境一致性。

**② `mcrnmf` 的版本门槛**
如果后续需要尝试 NMF-based MCR 作为 pyMCR 的补充，**当前 `spectra-all-in-one` 环境不一定满足 `mcrnmf` 的 `Python ≥3.11.9` 要求**。建议届时单独建一个 `mcr-nmf` 环境（`conda create -n mcr-nmf python=3.12`），而不是把 `mcrnmf` 塞进统一环境。

**③ 排除项**
**EEMs-toolkit（三维荧光 PARAFAC）** 开发环境为 Python 3.9.6，未官方声明支持 3.11，不建议强行塞入统一环境。如果三维荧光 PARAFAC 是核心需求，保留一个独立的 `eem` 环境（Python 3.10）。**seabreeze（仪器直连）** 推荐 Python 3.8–3.10，同样不适合与上述分析包混装。
