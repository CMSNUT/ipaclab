## 材料与方法

### 候选治疗靶点确定与归属分类

将成分靶点与疾病靶点取交集，获得候选治疗靶点。根据作用于每个候选靶点的黄芪成分数（AR）和附子成分数（AL）进行归属分类：

黄芪主导型靶点：AR / (AR + AL) ≥ 0.6

附子主导型靶点：AR / (AR + AL) ≤ 0.4

平衡型靶点：0.4 < AR / (AR + AL) < 0.6

分类结果以正文表格形式汇总展示，各靶点对应的具体成分及AR/AL计数详见**补充表4**。

### 靶点总体分布
将入血成分预测靶点与CHF疾病靶点取交集后，共获得 138个候选治疗靶点(图1a)。根据靶点是否仅由单味药成分作用，以及共有靶点中黄芪成分数（AR）与附子成分数（AL）的比例，将靶点分为五类：附子特有型（AL-Specific）、附子主导型（AL-Dominant）、黄芪特有型（AR-Specific）、黄芪主导型（AR-Dominant）和平衡型（Balanced）。分类标准为：若靶点仅由附子成分作用，则归为AL-Specific；若仅由黄芪成分作用，则归为AR-Specific；若靶点同时受两药成分作用，则计算AR/(AR+AL)，≥0.6为AR-Dominant，≤0.4为AL-Dominant，0.4–0.6为Balanced。

分类结果显示（表1），138个候选靶点中，黄芪特有型靶点69个（50.0%），附子特有型靶点13个（9.4%），黄芪主导型共有靶点19个（13.8%），附子主导型共有靶点13个（9.4%），平衡型共有靶点24个（17.4%）。从药物归属看，黄芪相关靶点（AR-Specific + AR-Dominant）共88个，占63.8%；附子相关靶点（AL-Specific + AL-Dominant）共26个，占18.8%；平衡型靶点24个，占17.4%。共有靶点56个，占候选靶点的40.6%；特有靶点82个，占59.4%。

从共有靶点内部看，附子主导型13个（23.2%），黄芪主导型19个（33.9%），平衡型24个（42.9%）。平衡型靶点在共有靶点中占比最高，提示黄芪与附子成分在近半数共有靶点上贡献相当，这些靶点可能是药对协同作用的核心节点。

### 附子主导型与附子特有型靶点
附子主导型共有靶点包括：MAPK8、MMP12、MMP3、NOS3、NR3C2、PDE3B、PDE4D、PDPK1、RXRA、PAH、HSP90AA1、ABCB1、ABCC2。附子特有型靶点包括：ABCG2、ACE、ACE2、CHRM2、ELANE、ERBB4、GAA、GATM、GBA1、GLB1、MGAM、SIGMAR1、UGCG。这些靶点主要涉及以下功能模块：

（1）肾素-血管紧张素-醛固酮系统（RAAS）与血管张力调控：ACE、ACE2、NR3C2（盐皮质激素受体）、NOS3（内皮型一氧化氮合酶）。ACE和ACE2是RAAS系统的关键节点，NR3C2是醛固酮受体，NOS3调节内皮功能。附子成分可能通过调节RAAS和NO信号影响血管张力和心脏负荷。

（2）心肌收缩与离子/胆碱能信号：CHRM2（毒蕈碱型乙酰胆碱受体M2）、PDE3B、PDE4D。PDE3B抑制可提高心肌细胞内cAMP水平，增强心肌收缩力；CHRM2参与迷走神经对心率的调控。这与附子“回阳救逆、温阳强心”的传统功效相符。

（3）应激激酶与基质重塑：MAPK8（JNK1）、MMP3、MMP12、HSP90AA1、PDPK1。MAPK8参与应激诱导的心肌凋亡和炎症；MMP3和MMP12参与细胞外基质降解和炎症细胞浸润；HSP90AA1稳定多种激酶和核受体；PDPK1是PI3K/Akt通路的上游激活因子。

（4）代谢与转运：ABCB1、ABCC2、ABCG2（ABC转运体）、GAA、GBA1、GLB1、MGAM（溶酶体/糖代谢）、PAH（苯丙氨酸代谢）、RXRA（维甲酸X受体，能量代谢）、UGCG（鞘脂代谢）。这些靶点提示附子成分可能影响药物转运、溶酶体功能和能量代谢。

总体而言，附子相关靶点数量虽少，但集中于RAAS、cAMP/PDE、MAPK应激、基质金属蛋白酶、核受体和转运体等关键心血管调控节点，体现了附子成分“靶点集中、作用核心”的特点，可能主要贡献于强心、血管调节和应激响应。

### 黄芪主导型与黄芪特有型靶点
黄芪主导型共有靶点包括：ADAM17、APOA2、CASP3、CFB、EGFR、ESR1、GC、MAPK1、MAPK10、MMP13、NQO1、PDE5A、SRC、TTR、EPHB4、FAP、REN、CTSS、FGFR1。黄芪特有型靶点共69个，代表性靶点包括：AKT1、BAX、BCL2、CASP8、CASP9、CAT、CCND1、CDKN1A、CPT1A、CRAT、CXCL8、CYP1A1、CYP1A2、CYP1B1、CYP2C19、CYP2C9、CYP2D6、EPO、ESR2、ESRRA、FABP4、HIF1A、HMGB1、HMOX1、IL2、JAK3、KCNH2、LCN2、LTA4H、LTF、MAPK3、MAPT、MIF、NFE2L2、NFKBIA、NPC1、NPR3、PEBP1、PGF、PLAU、PRDX1、RORC、SERPINA1、SLC5A2、SMN1、TAGLN、TLR2、TNF、TP53、TPI1、TXN、TXNRD1、UGT1A1、UGT1A9、UGT2B7、YAP1等。这些靶点覆盖范围广泛，主要涉及以下功能模块：

（1）PI3K-Akt信号通路与细胞存活：AKT1、EGFR、MAPK1、MAPK3、SRC、FGFR1、EPHB4、PDPK1（附子主导）等。黄芪成分可能通过激活或抑制PI3K-Akt通路，调节心肌细胞存活、凋亡和代谢。

（2）细胞凋亡调控：BAX、BCL2、CASP3、CASP8、CASP9、TP53、TNF。黄芪成分可能通过调节线粒体凋亡通路和内质网应激，减少心肌细胞凋亡。

（3）氧化应激与抗氧化防御：CAT、HMOX1、NQO1、NFE2L2、PRDX1、TXN、TXNRD1、CYP家族。黄芪成分可能通过激活Nrf2/ARE通路增强抗氧化能力，减轻心肌氧化损伤。

（4）炎症与免疫调节：TNF、CXCL8、IL2、JAK3、TLR2、HMGB1、NFKBIA、LTA4H、CTSS。黄芪成分可能通过抑制NF-κB和JAK-STAT通路，减轻心肌炎症反应。

（5）代谢调控：CPT1A、CRAT、FABP4、PPARG（平衡型）、RXRA（附子主导）、UGT1A1、UGT1A9、UGT2B7、SLC5A2。黄芪成分可能参与脂肪酸β-氧化、葡萄糖代谢和药物代谢。

（6）心肌重构与纤维化：MMP13、ADAM17、FAP、TGFBR1/2（平衡型）、TAGLN、YAP1、PGF、HIF1A。黄芪成分可能通过调节细胞外基质降解、成纤维细胞活化和血管生成，影响心肌重构。

黄芪相关靶点在数量上占绝对优势（88/138，63.8%），且功能覆盖炎症、凋亡、氧化应激、代谢和纤维化等多个维度，提示黄芪成分是药对广谱药理作用的主要贡献者，体现“益气”治本的配伍特点。

### 平衡型靶点
平衡型共有靶点共24个，包括：ALB、ANXA5、AR、BACE1、BCHE、BMP2、CA2、CES1、CFD、CTSD、DPP4、EPHX2、F2、HMGCR、KDR、MIF、MMP8、PDE4B、PIK3CG、PPARG、PTPN11、SHBG、TGFBR1、TGFBR2。这些靶点由黄芪和附子成分共同作用，且贡献比例接近，是药对协同作用的关键交汇点。功能上主要涉及：

（1）纤维化与心肌重构：TGFBR1、TGFBR2、BMP2、MMP8、CTSD。TGF-β信号通路是心肌纤维化的核心通路，平衡型靶点中包含TGFBR1/2，提示黄芪与附子成分可能协同调控心肌纤维化。

（2）代谢与能量稳态：PPARG、HMGCR、CES1、DPP4、EPHX2、CA2。PPARG是脂肪酸氧化和能量代谢的关键核受体；HMGCR参与胆固醇合成；DPP4与胰岛素抵抗和炎症相关。

（3）血管生成与内皮功能：KDR（VEGFR2）、ANXA5、F2、CFD。KDR是VEGF信号的主要受体，参与血管新生；F2和CFD参与凝血和纤溶平衡。

（4）信号转导与炎症：PIK3CG、PTPN11、MIF、BCHE、AR。PIK3CG和PTPN11参与PI3K和MAPK信号转导；MIF是促炎介质；AR（雄激素受体）可能参与心肌代谢调控。

平衡型靶点在共有靶点中占比最高（42.9%），表明黄芪与附子成分在近半数共有靶点上协同作用，而非单方面主导。这些靶点可能是药对“益气温阳”配伍发挥协同效应的分子基础。

### 靶点归属分类对药对配伍机制的意义
综合以上结果，黄芪-附子药对的靶点网络呈现以下特征：

（1）黄芪主导广谱调控，附子主导核心节点。黄芪相关靶点88个，覆盖炎症、凋亡、氧化应激、代谢和纤维化等多个通路，体现“益气”以调节整体心肌微环境的作用特点；附子相关靶点26个，数量较少但集中于RAAS、cAMP/PDE、MAPK应激、基质金属蛋白酶和核受体等关键心血管调控节点，体现“温阳”以强心、调节血管张力和应激响应的作用特点。

（2）共有靶点以平衡型为主，协同作用显著。56个共有靶点中，平衡型24个（42.9%），黄芪主导型19个（33.9%），附子主导型13个（23.2%）。平衡型靶点包括TGFBR1/2、PPARG、KDR、PIK3CG、PTPN11等，涉及纤维化、代谢、血管生成和信号转导，提示黄芪与附子成分在这些通路上贡献相当，可能通过协同调控发挥整合效应。

（3）靶点分类支持“益气治本、温阳治标”的配伍理论。黄芪主导型/特有型靶点侧重免疫炎症、凋亡、氧化应激和代谢调控，对应“益气”以改善心肌内环境；附子主导型/特有型靶点侧重RAAS、心肌收缩、离子通道和基质重塑，对应“温阳”以增强心功能和调节血流动力学。平衡型靶点则连接二者，形成协同网络。

（4）为后续核心基因和通路分析提供依据。黄芪主导型靶点中的AKT1、MAPK1、CASP3、EGFR、HIF1A、TNF、TP53等，以及附子主导型靶点中的MAPK8、NOS3、PDE3B、PDE4D、RXRA、HSP90AA1等，均是PI3K-Akt、HIF-1、MAPK、TNF、cAMP和RAAS等通路的关键节点，与CHF的病理生理过程密切相关。后续PPI网络分析、核心基因筛选和富集分析将在此基础上进一步聚焦药对治疗CHF的关键分子机制。

### 小结
本研究共获得138个候选治疗靶点。黄芪相关靶点88个（63.8%），附子相关靶点26个（18.8%），平衡型靶点24个（17.4%）。黄芪成分在靶点覆盖广度上占主导，主要调控免疫炎症、凋亡、氧化应激和代谢；附子成分靶点数量较少但集中于RAAS、cAMP/PDE、MAPK应激和基质重塑等核心心血管节点。共有靶点中平衡型占比最高，提示黄芪与附子成分在近半数共有靶点上协同作用。该分类结果从靶点层面揭示了黄芪-附子药对“益气治本、温阳治标、协同调控”的配伍机制，为后续核心基因筛选和通路富集分析奠定了基础。
