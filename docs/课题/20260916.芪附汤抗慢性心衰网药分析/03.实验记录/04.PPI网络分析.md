## 材料与方法

### STRING分析

将候选治疗靶点导入STRING数据库12.0版本（https://string-db.org/），物种选择Homo sapiens，最低相互作用置信度设为0.4，获取蛋白质-蛋白质相互作用（PPI）信息。

### PPI可视化

将PPI数据导入Cytoscape 3.10.3软件进行网络可视化，隐藏孤立节点后获得核心PPI网络，节点大小和颜色根据Degree值映射。CytoHubba插件计算MCC、Degree、Betweenness等11种拓扑参数。MCODE插件进行功能模块聚类（默认参数：Degree cutoff=2, Node score cutoff=0.2, K-core=2）。

## Hub基因确定

采用Cytoscape的CytoHubba插件计算各节点的MCC、Degree和Betweenness三种拓扑参数。取三种参数排名前50的靶点交集作为Hub基因。同时采用MCODE插件进行功能模块聚类分析（参数设置：Degree cutoff = 2，Node score cutoff = 0.2，K-core = 2），识别高密度功能模块。结合Hub基因和MCODE模块分析结果，确定同时存在于高得分模块中的Hub基因为核心基因（Core genes）。

PPI网络详细拓扑参数和MCODE模块成员见**补充表5**。


## 结果分析

### PPI网络与核心基因

STRING PPI网络包含候选靶点中的互作节点。CytoHubba拓扑分析显示，MCC、Degree和Betweenness三个参数排名前50的靶点取交集后获得Hub基因。结合MCODE模块分析（识别出若干高密度功能模块），确定核心基因（Core genes）若干个，包括AKT1、MAPK1、JUN、STAT3、TNF、IL6、CASP3、VEGFA等。核心基因在PPI网络中处于中心位置，形成紧密的互作子网络。
