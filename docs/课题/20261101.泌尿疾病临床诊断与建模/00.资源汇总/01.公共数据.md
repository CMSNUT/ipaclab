以下按**研究链条的环节**分类，以表格形式汇总数据库中可获取的资源、下载网址与访问方法。核心可及性判断先行：**绝大多数汇总统计层面资源（MR、eQTL、GWAS Catalog、FinnGen、OpenGWAS、GTEx、TCGA、GEO、PDB、AlphaFold、ZINC）均可在无特殊网络条件下公开或注册后下载**；需要正式申请的主要是 UK Biobank 个体级数据、CPTAC 受控数据和 PRACTICAL 个体级数据，但它们在**汇总统计或开放层级**上通常仍有替代入口，不影响 MR 与多组学建模的主链条。

## 六、按研究链条的选用建议

**若目标是“MR → 可药靶点 → 对接/MD”**，最短路径是：**OpenGWAS / FinnGen / GWAS Catalog 获取结局汇总统计 + eQTLGen / deCODE pQTL 获取暴露端 → TwoSampleMR + coloc + MR-PRESSO 完成因果与共定位 → PDB / AlphaFold DB 获取靶点结构 + ZINC / PubChem 获取配体库 → 对接与 MD**。这条路径的全部数据层资源均无需个体级申请，中国大陆可稳定访问。

**若目标是“多组学 ML + 单细胞验证”**，以 **UCSC Xena 的 TCGA-PRAD 开放矩阵**为训练/测试骨架，以 **GEO 中的单细胞 GSE** 为细胞分辨率验证层，必要时以 **CPTAC PDC 的开放蛋白质组**提供蛋白层面的佐证。这一组合在数据可及性和审稿认可度之间较为平衡。

**唯一需要提前规划申请周期的是 UK Biobank 个体级数据和 PRACTICAL 个体级数据**。但如果研究设计以汇总统计层面的 MR 为主体，UKB 汇总统计可通过 Pan-UKBB / GWAS Catalog 获取，PRACTICAL 汇总统计可通过其官网或 OpenGWAS 获取，**不构成实质性障碍**。

## 关键操作提示

**OpenGWAS 的 token 额度需要主动提升。** 注册后默认额度极低（约 100 次请求/10 分钟），必须在 Profile 页面填写用户信息后才能提升到足以支撑完整 MR 分析的额度。Token 存入 `.Renviron` 的 `OPENGWAS_JWT` 键后，`ieugwasr` 和 `TwoSampleMR` 会自动读取。

**FinnGen 的下载不是“一键打包”。** 需要先注册获取访问资格，然后从 manifest.tsv 中找到目标 endpoint 对应的 `path_https` 列链接，逐个下载 `.gz` 文件。前列腺癌风险使用 `C3_PROSTATE`；若需要排除其他癌症的对照定义，注意存在 `C3_PROSTATE_EXALLC` 变体。

**QTL 数据进入 TwoSampleMR 前需要列名对齐。** eQTLGen 和 GTEx 的 SMR 格式文件不能直接用 `fread()` 当作普通表格读入；要么用 SMR 软件查询目标基因的 cis-SNP，要么从 eQTLGen 的“Significant cis-eQTLs”页面提取文本记录后，手动映射为 `SNP`、`beta`、`se`、`effect_allele`、`other_allele`、`pval`、`eaf` 等标准列。deCODE 和 GoDMC 的下载文件同样需要先确认列名再进入 `harmonise_data()`。
