## 二、研究目的与研究价值

**总目的**：以血浆蛋白质组为暴露、前列腺癌为结局，通过**蛋白质组范围孟德尔随机化（PW-MR）+ 贝叶斯共定位**筛选具有因果证据的血浆蛋白，再经**可成药性评估、PheWAS安全性筛查和分子对接**，输出一个按证据等级分层的候选药物靶点清单及其配套的虚拟先导化合物，为前列腺癌的药物开发提供遗传学证据支持的上游靶点提名。

**研究价值**：

**第一，规避观察性研究的混杂与反向因果。** 血浆蛋白与前列腺癌的观察性关联受PSA检测行为、合并症和反向因果（肿瘤分泌蛋白）的严重混杂。MR以遗传变异作为工具变量，遗传变异在减数分裂时随机分配，且不受疾病状态影响，在满足排他性限制的前提下，其效应估计比观察性关联更接近因果。这一优势完全独立于SEER等临床数据库的治疗信息完整性。

**第二，在两个独立pQTL队列中做交叉验证，降低单队列的假阳性风险。** deCODE和UKB-PPP使用不同的蛋白质组学平台（SomaScan vs. Olink），两个平台的pQTL在效应方向和量级上的交叉一致性，是对MR结果可重复性的实质性检验，而非简单的“同一数据内的敏感性分析”。

**第三，从“因果蛋白”推进到“可成药靶点+虚拟先导化合物”的完整转化链。** 单纯的PW-MR论文以“提名靶点”为终点，临床转化距离较远。本方案在MR和共定位之后，增加可成药性分层（Tier 1/2/3）、PheWAS安全性筛查和分子对接，使产出形态从“关联清单”升级为 **“按证据等级和可成药性排序的靶点-化合物配对”** ，更接近药物发现的实际决策场景。

**第四，临床医生在靶点生物学合理性判断和现有PCa药物管线对照上具有不可替代的优势。** MR和对接是计算流程，但“这个靶点的生物学方向是否与PCa已知的致癌机制一致”“该靶点是否已被现有药物覆盖或存在已知的靶点类效应”“PheWAS提示的副作用是否在临床上可接受”这三个问题，需要临床背景来回答。这是纯生物信息学团队难以独立完成的部分，也是临床医生主导此类研究的核心竞争力。


## 三、研究内容

**内容一：前列腺癌GWAS meta分析数据的整合与工具变量筛选。** 以Schumacher 2018和Conti 2021的PCa GWAS meta分析（约94,397例 + 192,372对照）为结局数据源，提取与血浆蛋白pQTL显著相关的SNP作为工具变量。工具变量的筛选标准：与蛋白水平的关联达到全基因组显著性（通常P < 5×10⁻⁸，cis-pQTL可放宽至P < 5×10⁻⁶）；经过clumping（r² < 0.001，窗口10,000 kb）去除连锁不平衡；F统计量 > 10以排除弱工具变量；与结局GWAS中的协变量（如PSA检测行为）无已知关联。

**内容二：PW-MR的主分析——IVW、MR-Egger与加权中位数的三角验证。** 对每种蛋白，以IVW作为主效应估计（随机效应模型，以纳入工具变量间的异质性）；MR-Egger检验定向多效性（截距项偏离零提示多效性）；加权中位数提供对部分无效工具变量稳健的估计。三种方法的效应方向一致性作为“MR信号可辩护性”的第一道门槛——若IVW显著但Egger和加权中位数方向相反或不显著，该蛋白不进入后续共定位。

**内容三：贝叶斯共定位——区分“因果”与“连锁”。** MR显著仅说明蛋白水平与PCa风险存在遗传学上的因果关系，但pQTL和PCa GWAS信号可能来自同一区域内的不同因果变异（连锁不平衡导致的假阳性）。coloc通过贝叶斯因子比较五种假设（H0：无关联；H1/H2：仅蛋白或仅PCa关联；H3：两者关联但不同因果变异；H4：共享同一因果变异），以**PPH4 ≥ 0.8**作为强共定位证据。C5和SCP2在已发表研究中达到这一阈值，本方案将在此基础上扩大蛋白覆盖范围（3,722种可分析蛋白），并报告PPH3（提示同一区域存在两个独立信号）的蛋白，将其排除在Tier 1之外。

**内容四：可成药性分层与PheWAS安全性筛查。** 利用DrugBank、Open Targets或DGIdb等数据库评估蛋白的可成药性（是否有已知的小分子结合位点、抗体可及性、是否属于已验证的药物靶点家族）。按“共定位证据强度 × 可成药性”将蛋白分为Tier 1（PPH4 ≥ 0.8 + 可成药）、Tier 2（PPH4 + PPH3 ≥ 0.8 + 可成药）和Tier 3（共定位证据有限或不可成药）。对Tier 1和Tier 2蛋白，利用FinnGen或UK Biobank的PheWAS数据检验其遗传工具变量与广泛表型的关联，识别潜在的on-target副作用。

**内容五：分子对接与虚拟筛选。** 对通过全部前置筛选的Tier 1靶点，从PDB获取高分辨率蛋白结构（或使用AlphaFold预测结构），针对一个化学多样性良好的化合物库（如已发表的2,070分子库）进行分子对接。以结合能排序筛选Top 5配体，检查结合模式的合理性（是否落入已知的功能口袋、是否形成关键氢键/疏水相互作用）。β-Amyrone作为C5/SCP2双靶点抑制剂的提名是这一环节的可对标先例。


## 四、技术方案

### 4.1 数据源与预处理

| 数据层 | 来源 | 规模与内容 |
|---|---|---|
| **暴露（pQTL）** | deCODE Genetics | 4,907种蛋白，35,559名冰岛人；SomaScan平台 |
| **暴露（pQTL）** | UKB-PPP | 2,940种蛋白，54,219名UK Biobank参与者；Olink平台 |
| **结局（PCa GWAS）** | Schumacher 2018 + Conti 2021 meta分析 | 94,397例 + 192,372对照；欧洲裔为主，含跨ancestry成分 |
| **共定位** | 蛋白pQTL区域 ± 1 Mb | 提取与目标蛋白pQTL区域重叠的PCa GWAS summary statistics |
| **可成药性** | DrugBank / Open Targets / DGIdb | 靶点可成药性注释 |
| **PheWAS** | FinnGen / UK Biobank | 2,408种表型（FinnGen） |
| **蛋白结构** | PDB / AlphaFold DB | Tier 1靶点的实验结构或预测结构 |
| **化合物库** | 已发表筛选库 / Enamine / ChemDiv | 多样性化合物库（如2,070分子） |

### 4.2 工具变量构建与质量控制

对每种蛋白，从pQTL summary statistics中提取与蛋白水平显著相关的独立SNP：
- **显著性阈值**：cis-pQTL P < 5×10⁻⁸；trans-pQTL P < 5×10⁻⁶（trans信号较弱时放宽，但需在共定位中严格检验）。
- **LD clumping**：r² < 0.001，窗口10,000 kb，保留P值最小的SNP。
- **F统计量**：F = β² / SE²，F > 10。
- **Steiger filtering**：排除工具变量对结局的效应大于对暴露的效应的SNP，以降低反向因果风险。
- **与结局GWAS的协调**：确保工具变量在暴露和结局数据集中的效应等位基因一致，不兼容的SNP以palindromic SNP处理规则排除或校正。

### 4.3 MR估计与敏感性分析

| 方法 | 作用 | 判定规则 |
|---|---|---|
| **IVW（随机效应）** | 主效应估计 | P_FDR < 0.05（Benjamini-Hochberg校正） |
| **MR-Egger** | 定向多效性检验 | 截距项P > 0.05；若截距显著，报告Egger校正后的效应 |
| **加权中位数** | 对部分无效工具变量稳健的估计 | 与IVW方向一致 |
| **MR-PRESSO** | 离群SNP检测与校正 | 全局检验P > 0.05；若存在离群值，报告校正后估计 |
| ** Cochran's Q** | 异质性检验 | 高异质性时以随机效应IVW为主，并报告异质性来源 |

**三角验证规则**：只有IVW、MR-Egger和加权中位数**三者方向一致**，且MR-Egger截距不显著、MR-PRESSO未检测到显著离群值，该蛋白才进入共定位。这一规则比“仅看IVW的P值”更严格，可实质性降低多效性驱动的假阳性。

### 4.4 贝叶斯共定位

使用coloc包（或coloc.susie用于多个因果变异的情况），对每个通过MR三角验证的蛋白，提取其pQTL区域（± 1 Mb）和PCa GWAS在同一区域的summary statistics。先验概率设置为coloc的默认值（p1 = 1×10⁻⁴，p2 = 1×10⁻⁴，p12 = 1×10⁻⁵），并在敏感性分析中变化p12（如1×10⁻⁶和1×10⁻⁴）。

**分层规则**：
- **Tier 1**：PPH4 ≥ 0.8（强共定位）+ 可成药。
- **Tier 2**：PPH4 + PPH3 ≥ 0.8（提示性共定位）+ 可成药。
- **排除**：PPH3单独高（提示两个独立信号）或PPH4 < 0.5。

### 4.5 可成药性与PheWAS

可成药性评估依据：（1）蛋白是否有已知的小分子结合口袋（来自PDB结构或AlphaFold pocket预测）；（2）是否属于激酶、蛋白酶、G蛋白偶联受体等经典可成药家族；（3）是否有已进入临床阶段的靶向药物（如RRM2B的TRIAPINE）。

PheWAS：对Tier 1/2蛋白的工具变量，在FinnGen或UKB的广泛表型中进行MR或关联分析（不要求因果解释，仅作为安全性信号筛查）。若某蛋白的工具变量与心血管、代谢或免疫表型呈现强关联，在靶点优先级排序中标注该风险。

### 4.6 分子对接

对每个Tier 1靶点：
1. **结构准备**：从PDB获取实验结构（如C5: 1xwe；SCP2: 1qnd）或AlphaFold预测结构；去除水分子和无关配体；加氢；定义结合口袋（已知功能位点或pocket检测算法预测的位点）。
2. **配体准备**：化合物库的3D构象生成（如RDKit或Open Babel）；质子化状态按生理pH设定。
3. **对接**：使用AutoDock Vina或Glide进行对接；每个配体保留Top 9构象；以结合能（kcal/mol）排序。
4. **后筛选**：检查Top配体的结合模式是否合理（氢键网络、疏水包埋、与关键残基的接触）；排除结合能虽低但结合模式明显不合理的配体；报告Top 5配体的结合能和结合模式图。


## 五、技术路线

**第一阶段：数据获取与工具变量构建（第1–2周）**
获取deCODE和UKB-PPP的pQTL summary statistics、PCa GWAS meta分析summary statistics、FinnGen PheWAS数据、PDB结构文件和化合物库。按4.2的标准为每种蛋白构建工具变量，输出工具变量清单和F统计量分布。**关键检查**：工具变量的数量分布（cis-only vs. cis+trans）、弱工具变量比例、与结局GWAS的等位基因协调一致性。

**第二阶段：PW-MR与三角验证（第3–4周）**
对全部可分析蛋白（约3,722种）运行IVW、MR-Egger、加权中位数和MR-PRESSO。按4.3的三角验证规则筛选通过蛋白。**产出**：MR结果的全蛋白清单（效应量、P值、FDR校正P值、异质性检验结果）和通过三角验证的蛋白列表。此阶段计算量较大（数千次MR），需使用并行计算或TwoSampleMR的批量模式。

**第三阶段：贝叶斯共定位与靶点分层（第5–6周）**
对通过三角验证的蛋白，逐一运行coloc（或coloc.susie）。结合可成药性注释，按PPH4/PPH3将蛋白分为Tier 1、Tier 2和排除组。**产出**：靶点分层表，包含蛋白名称、基因、工具变量数、MR效应（OR及95% CI）、PPH4、可成药性类别、已知药物（若有）。

**第四阶段：PheWAS安全性筛查（第7周）**
对Tier 1和Tier 2蛋白的工具变量，在FinnGen或UKB表型中进行PheWAS。**产出**：每个Tier 1/2靶点的潜在on-target副作用清单，标注强度（P值、效应方向）和临床相关性评估。

**第五阶段：分子对接与虚拟筛选（第8–9周）**
对Tier 1靶点获取结构、准备化合物库、运行分子对接、后筛选Top配体。**产出**：每个Tier 1靶点的Top 5配体列表（结合能、结合模式、关键相互作用残基），以及双靶点或多靶点抑制剂的提名（若同一配体在多个Tier 1靶点上显示强结合）。

**第六阶段：整合、写作与投稿（第10–12周）**
整合五个阶段的产出，按TRIPOD+AI或STROBE-MR规范撰写论文。**核心表格**：（1）通过三角验证和共定位的蛋白分层表；（2）Tier 1靶点的PheWAS安全性摘要；（3）分子对接的Top配体表。**核心图件**：（1）MR-共定位-可成药性筛选流程图；（2）Tier 1靶点的森林图或火山图；（3）Top配体的结合模式图。


## 六、关键问题

**关键问题一：如何确保MR信号不是多效性或连锁不平衡的假阳性？**

这是PW-MR研究最核心的方法学挑战。本方案的应对是**三重过滤**：（1）MR三角验证（IVW、Egger、加权中位数方向一致 + Egger截距不显著 + PRESSO无离群值）排除多效性驱动的信号；（2）贝叶斯共定位（PPH4 ≥ 0.8）区分“共享因果变异”和“同一区域独立信号”；（3）两个独立pQTL队列（deCODE + UKB-PPP）的交叉一致性。三道过滤全部通过的蛋白，其MR信号的假阳性风险显著低于仅报告IVW P值的常规做法。**但需要明确**：即使三道过滤全部通过，MR仍不能替代随机试验；本方案的定位是“提供遗传学证据支持的上游靶点提名”，而非“证明靶向该蛋白一定能改善PCa结局”。

**关键问题二：deCODE与UKB-PPP的平台差异（SomaScan vs. Olink）如何影响交叉验证的可解释性？**

两个平台在蛋白覆盖范围、抗体特异性、动态范围和绝对/相对定量上存在差异，同一蛋白在两个平台上的pQTL效应量级可能不可直接比较。本方案不要求效应量的数值一致性，而是要求**效应方向的一致性**（在FDR校正后同时显著且方向相同）。若某蛋白仅在deCODE中显著而在UKB-PPP中不显著，将其标注为“单队列证据”，不纳入Tier 1，但可作为Tier 3报告。这一保守策略牺牲了部分敏感性，换取的是Tier 1靶点的可重复性。

**关键问题三：分子对接的虚拟筛选结果如何避免“对接得分高但无生物学意义”的假阳性？**

对接得分（结合能）与真实生物活性之间的相关性有限。本方案的应对：（1）**结合模式后筛选**——不仅看结合能，还要求配体落入已知的功能口袋或 predicted pocket，并与关键残基形成合理的氢键/疏水相互作用；（2）**化合物库的多样性控制**——使用Tanimoto相似度低的化合物库，避免结构冗余导致的虚假富集；（3）**双靶点交叉验证**——若同一配体在多个Tier 1靶点上显示强结合且结合模式合理，其作为多靶点抑制剂的优先级提升（如β-Amyrone对C5/SCP2的双靶点提名）。但对接结果**不声称“发现药物”** ，而是“提名值得实验验证的虚拟先导化合物”。

**关键问题四：临床医生在这项以计算为主的研究中，不可替代的贡献在哪里？**

MR、共定位和分子对接是标准化计算流程，生物信息学团队可以独立完成。临床医生的不可替代贡献集中在三个判断节点：（1）**靶点生物学方向的合理性**——MR给出的OR方向（风险 vs. 保护）是否与PCa已知的致癌机制一致？例如，一个在免疫微环境中预期起保护作用的蛋白，若MR显示为风险因素，需要检查工具变量是否捕获了错误的蛋白亚型或组织来源；（2）**PheWAS副作用的临床可接受性**——某个靶点的on-target副作用（如心血管事件或代谢紊乱）在PCa患者（多为老年男性，常伴合并症）中的临床后果，需要临床背景来判断；（3）**与现有药物管线的对照**——提名的靶点是否已被现有PCa药物（ARPI、PARP抑制剂、PSMA靶向治疗等）覆盖，或者是否代表了一个真正未满足的治疗缺口。这三个判断是研究从“计算输出”升级为“转化价值”的关键环节。


## 七、预期结果

**结果一：通过三重过滤的因果蛋白清单。** 预期在3,722种可分析蛋白中，约150–200种在FDR校正后与PCa风险显著相关（与eLife 2025报告的193种量级一致），其中约20–40种通过MR三角验证、在两个pQTL队列中方向一致、且PPH4 ≥ 0.8的强共定位证据。Tier 1靶点预计在**5–15个**量级（C5/SCP2研究从MR阳性蛋白中分层出2个Tier 1；eLife 2025提名了HSPB1、RRM2B、PSCA等可成药靶点）。

**结果二：Tier 1/2靶点的PheWAS安全性图谱。** 对每个Tier 1/2靶点，报告其工具变量与FinnGen/UKB表型的关联。预期部分靶点（如免疫相关蛋白）会显示与感染或自身免疫表型的关联，部分代谢相关靶点会显示与血脂或血糖的关联。这些信号不构成“禁止开发”的依据，但为靶点优先级排序提供安全性维度。

**结果三：Tier 1靶点的Top 5虚拟配体及结合模式分析。** 预期获得每个Tier 1靶点的5个候选配体（结合能、结合模式、关键相互作用残基），以及可能的双靶点/多靶点抑制剂提名。若同一配体在多个Tier 1靶点上显示合理结合，将其标注为“多靶点候选”，但明确声明这是虚拟筛选的假设生成结果，需实验验证。

**结果四：可发表的2–3区论文。** 目标期刊：*Frontiers in Immunology*（免疫相关靶点方向）、*Discover Oncology*（C5/SCP2研究的发表期刊，对MR+共定位+对接的框架有明确的发表先例）、*Journal of Translational Medicine*（转化医学方向）。论文的核心卖点不是“又一个PW-MR”，而是 **“MR三角验证 + 双队列交叉 + 共定位分层 + PheWAS安全性 + 分子对接”的完整证据链**——这一组合在已发表的前列腺癌PW-MR研究中尚未被系统性地整合在同一篇论文中。


**总结**：方案五的核心竞争力在于**数据获取门槛低**（全部为公开summary statistics，无需SEER访问权限、无需个体数据申请）、**方法学框架成熟**（MR、共定位和分子对接均有标准化的R包和先例）、**转化链条完整**（从因果蛋白到可分层靶点到虚拟配体）。临床医生的深度参与点不在计算流程本身，而在**靶点生物学合理性判断、副作用临床相关性评估和与现有药物管线的对照**——这三个判断决定了研究是停留在“计算清单”还是升级为“有转化价值的靶点提名”。
