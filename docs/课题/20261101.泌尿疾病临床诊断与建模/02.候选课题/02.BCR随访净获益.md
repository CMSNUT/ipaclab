## 一、研究背景与研究动机

### 1.1 临床问题：BCR随访中“何时该行动”缺乏决策层面的证据

根治性前列腺切除（RARP）后，生化复发（BCR）的监测是泌尿外科随访中最高频的临床场景之一。BCR通常定义为PSA术后可检测并持续上升，提示潜在的局部残留或远处微转移。一旦确认BCR，临床面临的核心决策是：**是否启动挽救性治疗、在什么时间点启动、以及以什么频率继续监测**。然而，当前随访策略的制定在很大程度上依赖于**静态的基线风险分层**（如CAPRA评分、D'Amico风险组、术后Gleason和切缘状态），这些信息在手术那一刻就已经固定，无法反映术后PSA轨迹中逐步显现的动态信号。

这一“静态规则主导随访”的实践与PSA的生物学本质之间存在结构性错配。PSA是一个**纵向、高频、低成本**的生物标志物，其术后轨迹（下降速度、nadir水平、上升斜率）携带了关于残余疾病负荷和生物学侵袭性的连续信息。2023年发表于 *International Journal of Radiation Oncology, Biology, Physics* 的CHHiP III期试验分析已经证明，基于纵向PSA的联合动态预测模型在8年随访期内达到了平均AUC 0.70和Brier score 0.10，且PSA值和变化速率均对复发具有预测作用。更近期的工作（2025年）使用可更新机器学习模型整合纵向PSA，报告在第5年BCR预测AUC达到0.93，并声称可安全减少59%的PSA检测。

**但这些工作几乎全部将终点锚定在判别力指标上，而非决策净获益**。一个AUC更高的动态模型，在临床决策上是否真的优于一个简单、静态的风险规则，取决于动态信息在**哪个随访时间窗口**开始产生足以改变行动的增量，以及这一增量在多大的决策阈值范围内是稳健的。这一问题至今没有被系统回答。

### 1.2 方法学缺口：“动态更新优于静态规则”是一个未被检验的默认假设

在预测建模文献中，“动态模型优于静态模型”几乎被当作一个自明的命题。但2021年发表于 *JAMA Network Open* 的一项直接比较研究提供了重要的反例：在去势抵抗性前列腺癌中，界标模型（landmark model）和联合模型（joint model）在预测影像学进展时表现相当，且**模型选择对PSA轨迹线性假设的依赖程度因随访时间点而异**。这说明“动态更新”的增益并非无条件成立，它取决于数据结构、预测时间窗和方法假设之间的具体匹配关系。

更重要的是，**判别力的增量不等于决策的增量**。一个模型可能在AUC上提升了0.05，但如果这一提升集中在临床不会采取行动的阈值区间之外，它对患者结局的影响为零。决策曲线分析（DCA）正是为回答这一问题而设计的框架：它通过**净获益**这一指标，将真阳性（正确识别需要干预的患者）和假阳性（不必要干预）按照临床医生或患者愿意接受的阈值概率进行加权，从而直接比较不同规则在“采取行动”与“不采取行动”之间的权衡。DCA已经在早期PSA反应预测、多组学预后签名评估等场景中被用于检验模型的临床效用，但**尚未被系统应用于“静态规则 vs. 动态更新规则”在BCR随访中的头对头比较**。

### 1.3 研究动机：从“模型是否更准”转向“动态信息在何时真正改变了决策”

本课题的核心动机不是构建一个性能更高的BCR预测模型，而是回答一个**决策导向的边界问题**：

> **在RARP后BCR随访中，基于纵向PSA的动态更新规则，相对于一个仅使用基线特征的静态风险规则，在什么随访时间点上开始产生正的增量净获益？这一增量的幅度和稳健性在多大的决策阈值范围内成立？**

这一问题的答案无论方向如何都具有发表价值。如果动态更新在多个时间点上产生稳健的正增量，它为“在BCR随访中常规整合PSA轨迹”提供了决策层面的证据；如果增量有限或集中在狭窄的时间窗口内，它则对当前“动态模型天然优于静态模型”的默认假设提出必要的限定，并帮助临床医生识别**在哪些随访节点上，复杂的动态建模是真正值得的**。

## 二、研究内容

本课题围绕一个主问题和三个子问题展开。

**主问题**：在Zenodo公共数据集（600例RARP后前列腺癌患者，含基线、3个月、6个月、12个月PSA及BCR状态和日期）上，动态更新规则相对于静态规则在预设随访节点（第12、24、36个月）的**增量净获益**是多少，增量首次为正的时间点在哪里？

**子问题1（模型构建与验证）** ：静态规则（基线Cox或正则化Cox）和动态规则（联合模型或界标法结合PSA更新）在时间依赖AUC、Brier score和校准度上的相对表现如何？动态规则的优势是否依赖于特定的方法选择（联合模型 vs. 界标法）？

**子问题2（决策增量）** ：在DCA框架下，两条规则的净获益曲线在多大的阈值概率范围内存在有临床意义的差异？增量净获益（ΔNB）是否在预设的决策阈值区间内（例如，临床医生在BCR随访中可能考虑启动挽救性治疗的阈值概率，通常位于15%—40%区间）稳定为正？

**子问题3（时间边界与稳健性）** ：ΔNB首次为正的随访时间点是什么？这一时间边界在bootstrap重抽样、不同缺失数据处理策略和不同DCA阈值范围下是否稳健？动态规则的增量是否集中在PSA轨迹信息量最丰富的患者亚组中（例如，PSA下降至nadir的速度较慢或nadir水平较高的患者）？

## 三、材料与方法

### 3.1 数据来源与获取

**数据集**：Zenodo前列腺癌综合临床、病理与随访数据集（DOI: 10.5281/zenodo.15007105），发布于2025年3月11日，包含**600例**前列腺癌患者的**30个变量**，涵盖初始诊断信息（PSA、临床分期、活检Gleason评分）、风险分层、实验室值（白蛋白、淋巴细胞计数、CRP、NLR、CALLY指数）、治疗信息和随访结局。该数据集在BCR动态研究中的可用性已被独立工作验证：一项2026年发表于Zenodo的分析使用同一600例队列，报告PSA/CRP相关的“平台区域”内BCR率为59.8%，而平台区域外为18.3%，提示该数据集的PSA纵向信息与BCR结局之间存在可检测的动态关联。

**关键变量**：基线临床变量（年龄、术前PSA、Gleason评分、临床分期、切缘状态等）、纵向PSA测量值（基线、术后3个月、6个月、12个月）、BCR状态（二值）和BCR日期/末次随访日期（用于时间-事件结局）。需在数据清洗阶段确认PSA测量时间点与BCR定义的时间锚点（手术日期）是否对齐，以及缺失PSA测量的分布模式。

**获取方式**：数据集以开放许可在Zenodo上公开，中国大陆可直接下载，无需申请或注册。数据获取不构成研究的时间瓶颈。

**样本量与事件数评估**：600例的队列规模在BCR预测研究中属于中等偏小。根据BCR的典型发生率（RARP后5—10年约20%—40%），预期事件数可能在120—240之间。这一事件数**足以支撑方法学原型和决策曲线分析**，但不足以支撑高维模型或复杂的亚组分析。因此，本课题的模型设计必须遵循**简约原则**：静态规则和动态规则均应控制在低维参数空间内，避免过拟合。这一约束本身与课题的决策导向定位是一致的——**一个在600例上可靠估计的简约规则，比一个在同样样本上过拟合的复杂模型更具临床可信度**。

### 3.2 研究设计

**总体设计**：回顾性队列研究，方法学比较与决策分析。采用**交叉验证**或**bootstrap**进行内部验证，避免使用单一随机划分导致的乐观偏倚。考虑到样本量限制，不设置独立的外部验证集，但通过**重复交叉验证**和**bootstrap乐观度校正**来评估规则的稳健性，并在讨论中明确外部验证的必要性。

**随访节点**：预设**第12、24、36个月**作为动态预测的评估时间点。选择这三个节点的理由是：（1）与数据集PSA测量的时间覆盖（3、6、12个月）和典型BCR随访节奏对齐；（2）12个月是术后早期，PSA轨迹的信息量尚有限；（3）24和36个月进入BCR风险上升期，动态更新的潜在价值更大。如果数据集的随访时间分布允许，可额外探索第48或60个月作为敏感性分析。

**结局定义**：BCR定义为术后PSA达到或超过某个阈值（通常为0.2 ng/mL并确认上升，或按数据集原始定义）。需在分析前从数据字典中明确BCR的操作性定义，并在补充材料中报告。

### 3.3 静态规则的构建

静态规则仅使用**在手术时点可获取的基线变量**，不纳入任何术后PSA测量。模型选择遵循简约原则：

- **主模型**：Cox比例风险模型，纳入预先选择的基线变量（术前PSA、Gleason评分分组、切缘状态、病理分期），变量数量控制在事件数的1/10以下（如果事件数约为150，则变量数≤5—6）。
- **敏感性模型**：正则化Cox（LASSO或弹性网）作为替代，用于检验变量选择对结果的影响。
- **输出**：在预设随访节点上，静态规则为每位患者给出一个**固定的**BCR风险预测（基于基线变量的线性预测子），不随PSA更新而变化。

如果数据集中包含可用的列线图或风险评分（如CAPRA的组成部分），可将其作为静态规则的基准进行比较，以增强临床可解释性。

### 3.4 动态规则的构建

动态规则在基线变量的基础上，**纳入术后PSA的纵向信息**。本课题采用两种互补的动态建模路径，以检验方法选择对决策增量的影响。

**路径A：联合模型（Joint Model）** 。联合模型由一个纵向PSA子模型（线性混合效应模型，以时间、基线协变量及其交互为固定效应，患者随机截距和随机斜率为随机效应）和一个时间-事件BCR子模型（Cox或参数化风险模型）组成，两者通过共享随机效应或当前值关联。联合模型的优势在于它**显式地建模PSA轨迹的生成过程与BCR风险之间的关联**，能够在每个随访节点上基于患者的PSA历史更新条件风险预测。CHHiP试验的分析已经展示了联合模型在局部前列腺癌动态预测中的可行性。在600例数据上，联合模型的参数化需保持简约：纵向子模型可考虑线性或分段线性轨迹，避免高阶多项式。

**路径B：界标法（Landmarking）** 。在每个预设的界标时间点（12、24、36个月），仅使用在该时点之前可获取的信息（包括截至界标时的PSA测量值和PSA变化指标，如斜率或nadir至界标的PSA变化），拟合一个Cox模型预测界标之后的BCR风险。界标法的优势在于**计算简单、对纵向轨迹的分布假设较少**，且已有前列腺癌研究显示其预测性能可与联合模型相当。界标法的一个关键设计选择是PSA变化指标的构造：可以考虑**当前PSA水平**和**界标前PSA斜率**（线性混合效应估计）作为两个独立的动态预测因子，类似于CRPC比较研究中“LMslope”的设计。

**方法选择的意义**：路径A和路径B代表了动态建模中“参数化程度较高、但生物学解释更丰富”和“参数化程度较低、但更稳健”的两端。如果两种路径在决策增量上给出一致的结论，则结论对方法选择是稳健的；如果分歧，则分歧本身构成对“动态更新”概念边界的重要刻画。

### 3.5 决策曲线分析（DCA）

**净获益的定义**：在阈值概率 \( p_t \) 下，净获益 \( \text{NB} = \frac{\text{真阳性数}}{N} - \frac{\text{假阳性数}}{N} \times \frac{p_t}{1-p_t} \)。其中“阳性”定义为在预设时间窗口内发生BCR。净获益的临床含义是：在愿意接受 \( p_t/(1-p_t) \) 的“每避免一例漏诊所允许的过度干预代价”的前提下，规则相对于“全部干预”或“全部不干预”的额外价值。

**比较策略**：在**每个预设随访节点**上，分别绘制以下策略的决策曲线：
- **静态规则**：基于基线变量的固定风险预测，在节点上采取“如果预测风险≥ \( p_t \) 则视为高风险/需行动”。
- **动态规则A（联合模型）** ：基于截至节点的PSA历史更新后的条件风险预测。
- **动态规则B（界标法）** ：基于界标时点的PSA水平和斜率更新的风险预测。
- **参照策略**：“全部行动”（treat all）和“全部不行动”（treat none）。

**增量净获益（ΔNB）** ：动态规则的净获益减去静态规则的净获益，在阈值概率网格上计算。**ΔNB的置信区间**通过bootstrap（1000次重抽样）获得，以判断增量在统计上是否可区分于零。

**临床相关阈值区间**：DCA的阈值范围不应机械地覆盖0—1，而应聚焦于**临床医生在BCR随访中可能实际考虑启动挽救性治疗的阈值概率区间**。参考已有前列腺癌DCA工作，这一区间大致在**15%—40%** 之间。如果数据集的BCR患病率和临床背景提示不同的决策阈值，应相应调整并报告调整依据。**ΔNB在预设临床阈值区间内的方向和幅度，而非在全阈值范围内的“曲线下面积”，是本课题的主要决策终点**。

### 3.6 时间边界的识别与稳健性分析

**ΔNB首次为正的时间点**：在12、24、36个月三个节点上分别计算ΔNB及其bootstrap置信区间。如果ΔNB在12个月不显著、但在24或36个月显著为正，则“动态更新的决策增量首次出现的时间边界”可被定位在12—24个月之间。如果三个节点均不显著，则结论为“在本数据的样本量和事件数下，动态更新相对于静态规则未产生可检测的决策增量”。

**稳健性检验**：
- **缺失数据处理**：PSA测量的缺失模式（完全随机缺失 vs. 非随机缺失）可能影响动态规则的有效信息量。主分析采用**多重插补**或**在联合模型框架内处理缺失**，敏感性分析采用**完整案例分析**（仅纳入在节点前有完整PSA测量的患者），比较两种策略下ΔNB的差异。
- **Bootstrap乐观度校正**：对静态和动态规则的净获益曲线进行bootstrap乐观度校正，报告校正后的ΔNB，以避免小样本下的乐观偏倚。
- **DCA阈值范围的敏感性**：将临床相关阈值区间在15%—40%的基础上上下扩展（如10%—50%），检验ΔNB的方向性是否依赖于阈值区间的选择。
- **BCR定义敏感性**：如果数据集允许，检验不同BCR阈值定义（如0.2 ng/mL vs. 0.1 ng/mL并确认上升）对结果的影响。

### 3.7 样本量与统计效力考量

600例的样本量对DCA的净获益估计构成了**精度上的约束**。净获益的标准误依赖于事件数和阈值概率，在阈值概率较高（如>30%）时，净获益的置信区间可能较宽。**本课题不将以“统计显著性”作为ΔNB存在的唯一判据**，而是同时报告ΔNB的点估计、bootstrap置信区间和**决策一致性**的辅助指标（例如，在预设阈值下，动态规则相对于静态规则改变推荐的患者比例，以及在这些被改变推荐的患者中，实际BCR状态如何）。这种“效应量+不确定性+决策影响”的组合报告方式，更符合小样本决策分析的实际解读需求。

## 五、预期研究结果

基于现有文献的信号和数据的结构特征，可以合理预期以下几类结果。

**关于判别力**：动态规则在24和36个月节点上的时间依赖AUC预期高于静态规则，但在12个月节点上差异可能较小或不显著。CHHiP联合模型报告的平均AUC约为0.70，而动态ML在更大队列中报告的AUC可达0.93；Zenodo数据集的600例和预期事件数决定了AUC更可能落在0.70—0.80的区间，而非高90s。联合模型和界标法的AUC差异预期不大，与CRPC比较研究的发现一致。

**关于DCA增量**：**本课题最有价值的预期结果形态不是“动态规则在所有节点上均显著优于静态规则”，而是一种时间依赖的、阈值依赖的分化模式**。合理的预期是：在12个月节点，ΔNB在临床阈值区间内可能不显著，因为术后早期的PSA信息尚未充分分化；在24个月节点，ΔNB可能在中等阈值概率（20%—35%）范围内为正，因为此时PSA轨迹已经积累了足够的信息来区分“稳定低值”和“缓慢上升”的表型；在36个月节点，ΔNB的幅度可能进一步增大，但bootstrap置信区间可能变宽，反映事件数随时间的减少。**如果这一分化模式出现，它本身就是对“动态更新何时值得”的具体回答**——不是“动态总是更好”，而是“动态更新在24个月之后、在中等决策阈值下开始产生可检测的决策增量”。

**关于方法路径**：联合模型和界标法的ΔNB可能在方向和幅度上一致，但在极端阈值或节点上出现分歧。如果分歧出现，联合模型可能在PSA轨迹信息更丰富的患者中表现更优，而界标法在PSA测量不完整的患者中更稳健。

**关于负结果的可能性**：在600例和有限事件数的约束下，ΔNB的bootstrap置信区间在部分阈值和节点上可能跨越零。**这一结果本身不构成研究的失败**，而是对“动态更新在中小样本中的决策可检测性”的边界刻画。讨论中将明确区分“动态更新不产生决策增量”（证据支持无效）和“本样本量不足以检测到增量”（证据不足），并通过决策一致性分析和效应量报告来支撑这一区分。


## 六、深入讨论的规划

### 6.1 核心讨论点一：判别力增量与决策增量的解耦

如果AUC显示动态规则优于静态规则，但ΔNB在临床阈值区间内不显著或狭窄，讨论的核心将围绕**“为什么更准的模型不一定改变决策”** 展开。可能的原因包括：（1）AUC的增量集中在临床不会采取行动的阈值范围之外；（2）动态规则虽然重新排序了患者，但排序的变化没有落在决策边界附近；（3）PSA轨迹的增量信息与基线变量高度相关，在基线风险已经足够极端的患者中，动态更新不改变行动方向。这一讨论将直接回应BCR预测文献中“AUC导向”评价范式的局限，并与DCA方法学文献中关于“判别力与净获益非线性关系”的论述形成对话。

### 6.2 核心讨论点二：动态更新“时间边界”的临床与方法学含义

如果ΔNB首次为正的时间点被定位在24个月或更晚，讨论需要同时处理**临床解释**和**方法学解释**。临床解释方面：术后12—24个月是PSA从术后下降期过渡到稳定期或上升期的关键窗口，动态更新的价值可能在于捕捉这一过渡的异常。方法学解释方面：联合模型和界标法在早期节点上可能受到PSA测量次数不足（仅有基线、3个月、6个月、12个月）的限制，动态信息的“积累速度”本身是一个需要时间的过程。如果动态更新的增益在24个月才出现，这对随访设计有一个直接的启示：**在术后早期（<12个月）使用复杂动态模型可能是不必要的，而在24个月之后，动态信息的决策价值开始值得被系统性利用**。

### 6.3 核心讨论点三：联合模型与界标法的选择——简约性、稳健性与临床可部署性

即使两种方法在ΔNB上一致，它们在**临床可部署性**上的差异仍然值得讨论。联合模型提供了对PSA轨迹与BCR风险关联的显式参数化，生物学解释更丰富，但计算复杂度更高、对轨迹函数形式的假设更强。界标法计算简单、对分布假设更少，更容易被临床研究者在标准统计软件中实现和复现。在600例的小样本场景中，**界标法的稳健性可能比联合模型的参数化优雅更具实际价值**。讨论中将结合CRPC比较研究的发现（两者性能相当，但界标法在部分时间点上更稳定）和本课题的DCA结果，给出方法选择的务实建议。

### 6.4 核心讨论点四：本研究的边界与外部验证的必要性

讨论必须诚实地界定本研究的边界。600例的单队列、无外部验证、随访时间点的覆盖有限（至12个月PSA，随访至36个月），意味着ΔNB的估计具有**样本特异性**。PSA测量间隔的规则性（3、6、12个月）也与真实世界的不规则随访存在差异，后者可能削弱动态规则在实际部署中的增量。讨论中将明确：本课题的贡献在于**提供方法学框架和初步的决策证据**，而非确立一个可直接临床部署的规则。外部验证（例如，在更大规模的规则随访队列或真实世界不规则随访数据上）是下一阶段的必要步骤，并讨论在外部验证中应优先关注的偏移维度（随访间隔分布、BCR定义、人群疾病谱）。

### 6.5 核心讨论点五：对BCR随访策略设计的启示

如果结果支持动态更新在特定时间窗口和阈值区间内产生正增量，讨论将延伸到一个更具体的临床问题：**是否应该根据动态规则的输出调整PSA检测的频率**，而非仅仅调整“是否干预”的阈值。例如，如果动态规则在24个月时识别出一组“PSA轨迹稳定但基线高风险”的患者，其后续BCR风险仍然很低，那么减少这些患者的PSA检测频率可能是一个合理的降阶梯策略。这一讨论将把课题的决策框架从“单次行动”扩展到“随访节奏的设计”，并与近期关于“动态ML可安全减少59% PSA检测”的工作形成对话，但强调本课题的DCA框架为“减少检测”提供了一个比AUC更严格的评估基础。

## 代码

以下是一份可直接在 RStudio 中渲染的 Quarto（`.qmd`）代码模板，对应你此前确定的**课题一**：在 Zenodo 600 例前列腺癌随访数据上，比较**静态 Cox 规则**与**动态规则（联合模型 + 界标法）** 在 RARP 后 BCR 随访中的**净获益增量（ΔNB）**。代码按“数据准备 → 静态模型 → 动态模型 → 判别力 → DCA → 时间边界 → 敏感性分析 → 图表输出”的顺序组织，每个代码块都标注了与方案章节的对应关系，以及**必须根据实际 Zenodo 数据集变量名修改的位置**。

由于无法直接访问 Zenodo 数据集，代码中**数据读取部分使用 `read.csv()` 占位，并提供了一个模拟数据生成块**，用于在真实数据尚未下载时先跑通流程。替换为真实文件路径后，即可逐步生成主图与补充图表。

### ⚠️ 运行这份代码前需要完成的 5 件事

**第一，替换数据路径与变量映射。** 代码中 `path` 和 `transmute()` 里的变量名是占位符。下载 Zenodo 数据集后，必须根据其数据字典把 `id`、`time`、`status`、`psa_base`、`gleason`、`margin`、`stage`、`psa_3m/6m/12m` 映射到真实列名。如果数据集的随访时间单位是“天”而非“月”，需要在 `time` 映射时除以 30.44。

**第二，确认 BCR 的操作性定义。** 代码假设 `status = 1` 表示 BCR，`time` 是从手术日期到 BCR 或末次随访的时间。如果 Zenodo 数据集使用不同的定义（例如 PSA ≥ 0.2 并确认上升 vs. 仅单次 ≥ 0.2），需要在 `data-import` 块中调整 `status` 的派生逻辑，并在 `sensitivity-bcr-def` 中报告不同定义下的敏感性。

**第三，`JMbayes2` 的收敛与计算时间。** 联合模型在 600 例数据上可能需要数分钟到数十分钟的 MCMC 时间，取决于迭代次数和随机效应结构。建议先用 `n_iter = 2000, n_burnin = 500` 跑通流程，用 `traceplot()` 检查收敛，再逐步增加至 `n_iter = 10000, n_burnin = 2000` 用于正式分析。如果 `JMbayes2` 在你的数据上收敛困难，可以切换到 `joineRML::mjoint()`（频率学派），但需要相应调整 `predict()` 的调用方式。

**第四，DCA 的阈值范围必须临床化。** 代码中默认 `thresholds = seq(0.05, 0.60, by = 0.01)`，但方案明确要求聚焦于 **15%—40%** 的临床相关区间。在正式分析中，主图应聚焦于这一区间，并将全范围作为补充材料。`dcurves` 的 `plot()` 支持 `thresholds` 参数，需要在 `dca()` 中传入与临床区间匹配的网格。

**第五，bootstrap 的 ΔNB 计算是自定义环节。** 代码中 `dca-delta-nb` 块提供了框架，但 **bootstrap 循环内的模型重拟合与净获益计算需要根据你最终的预测对象（静态风险向量、联合模型预测、界标法预测）逐一实现**。建议将每个规则的预测封装为函数，在 bootstrap 中调用，确保 ΔNB 的置信区间反映模型估计和规则比较的双重不确定性。

```{r landmark-dataset}
#| label: landmark-dataset
#| eval: true
#| tbl-cap: "界标数据集构建：在每个节点上纳入截至该节点的 PSA 信息"

make_landmark_data <- function(data_wide, tL) {
  data_wide %>%
    filter(time >= tL) %>%                     # 仅纳入在 tL 时仍在风险集中的患者
    mutate(
      time_from_landmark = time - tL,
      status_after_landmark = status
    ) %>%
    # 构造截至 tL 的 PSA 动态特征
    mutate(
      psa_at_landmark = case_when(
        tL >= 12 ~ psa_12m,
        tL >= 6  ~ psa_6m,
        tL >= 3  ~ psa_3m,
        TRUE     ~ psa_base
      ),
      psa_slope_to_landmark = case_when(
        tL >= 12 ~ (psa_12m - psa_3m) / 9,
        tL >= 6  ~ (psa_6m  - psa_3m) / 3,
        TRUE     ~ NA_real_
      )
    ) %>%
    filter(!is.na(psa_at_landmark))
}

# 计算时间依赖 AUC 和 Brier score 的函数框架
# 实际分析中需将 risk 向量与 time/status 对齐
compute_metrics <- function(time, status, risk, t_event) {
  # time-dependent AUC（timeROC）
  roc <- timeROC(
    T = time, delta = status, marker = risk,
    cause = 1, times = t_event, iid = TRUE
  )
  auc <- roc$AUC[2]   # 对应 t_event 的 AUC

  # Brier score（tdROC）
  brier <- tdROC::tdROC(
    X = time, Y = status, pred.prob = risk,
    tau = t_event
  )$Brier

  tibble(AUC = auc, Brier = brier)
}

## 7b. 临床影响曲线（CIC）：DCA 的“人数”翻译

CIC 回答的是 DCA 无法直接回答的问题：**在某个阈值下，模型会把每 1000 人中多少人标记为高风险，其中多少人真正发生了 BCR**。它不改变 DCA 的结论，而是把净获益这一抽象加权值翻译为临床可感知的工作量和误判规模。

```{r cic-manual-function}
#| label: cic-manual-function

# ============================================================
# 手动 CIC 计算函数（生存结局版）
# 输入：
#   time, status : 生存结局（与 DCA 使用的完全一致）
#   risk         : 模型预测的风险向量（与 DCA 使用的完全一致）
#   time_horizon : 事件时间窗（月），如 t = 24 节点上看 12 个月内的 BCR
#   thresholds   : 阈值网格，与 DCA 保持一致
#   n_per        : 模拟队列规模，默认 1000
# 输出：每个阈值下的
#   n_high_risk        : 每 1000 人中模型标记为高风险的人数
#   n_high_risk_event  : 其中真正发生事件的人数（KM 估计）
# ============================================================

compute_cic <- function(time, status, risk,
                        time_horizon,
                        thresholds = seq(0.05, 0.60, by = 0.01),
                        n_per = 1000) {

  stopifnot(length(time) == length(status),
            length(time) == length(risk))

  res <- lapply(thresholds, function(pt) {
    high <- risk >= pt
    n_high <- sum(high)

    if (n_high == 0) {
      p_event_given_high <- 0
    } else {
      # 高风险组内的事件概率，用 KM 处理删失
      km <- survival::survfit(
        survival::Surv(time[high], status[high]) ~ 1
      )
      s <- summary(km, times = time_horizon)$surv
      p_event_given_high <- 1 - ifelse(length(s) == 0 || is.na(s), 0, s)
    }

    tibble(
      threshold          = pt,
      n_high_risk        = n_per * mean(high),
      n_high_risk_event  = n_per * mean(high) * p_event_given_high,
      n_high_risk_false  = n_per * mean(high) * (1 - p_event_given_high)
    )
  })

  bind_rows(res) %>%
    mutate(
      # 高阈值下高风险组人数过少时，KM 估计不稳定，标记提示
      unstable = n_high_risk < 20
    )
}

### 🎯 CIC 在课题一叙事中的定位

DCA 和 CIC 在你的论文中承担**不同层次的论证任务**，不能在正文中混为一谈。

**DCA（图 3）是主要终点**，用于回答“动态规则是否值得用”——ΔNB 在 15%—40% 阈值区间内是否显著为正。这是方法学层面的准入判断。

**CIC（图 4）是关键的可操作性证据**，用于回答“用了之后会怎样”。它的核心读法是**看两条曲线的间距随阈值的变化**：在临床相关阈值（如 20%—30%）下，如果动态规则相对于静态规则把红线（高风险总人数）**向下推**，同时蓝线（真阳性人数）**基本持平或仅轻微下移**，这意味着动态规则在不牺牲真阳性的前提下**减少了不必要的标记**，也就是减少了不必要活检或提前干预的人数。反之，如果红线下降但蓝线也同步大幅下降，则说明减少的工作量是以漏诊为代价的，这与 DCA 的 ΔNB 结论应当相互印证。

**在讨论中的写法建议**：先报告 DCA 的 ΔNB 结论（“动态规则在 24 个月、25%—35% 阈值区间内 ΔNB 为正，bootstrap CI 不含零”），再用 CIC 给出人数翻译（“在同一区间内，每 1000 名随访患者中，动态规则较静态规则减少约 X 例高风险标记，其中真阳性人数减少约 Y 例，净减少的假阳性标记约 X−Y 例”）。这种“先净获益、后人数”的报告顺序，既满足了方法学审稿人对决策分析严谨性的要求，也满足了临床审稿人对“这个模型到底影响多少病人”的实际关切。

### 📚 直接使用该数据集的研究

**1. Kabongo R. Maladaptive Plateau Detection in Prostate Cancer: Pathological Stabilization Across Cohort Observation-Space and Longitudinal PSA Dynamics. Zenodo. 2026 (v1.1).**

这是目前**唯一一篇明确以该600例队列为核心分析对象并报告具体结果**的文献。该研究提出“适应不良平台（maladaptive plateau）”框架，核心发现是：在该600例前列腺癌队列中，**PSA/CRP相关的“平台区域”内生化复发（BCR）率为59.8%，而平台区域外仅为18.3%**；在Risk Group 3患者中，平台阳性者的BCR率为59.6%，平台阴性者为18.2%。研究还将该队列的“队列观察空间映射”与另一份放疗后纵向PSA数据的“个体轨迹分析”并列，论证“癌症复发不仅是生物标志物升高，更是病理性的稳定化——疾病相关标志物在错误的生物学方向上形成持续的低动态 regime”。

# ============================================================
# R/download-zenodo.R —— Zenodo 自动下载（带降级）
# ============================================================

download_zenodo <- function(record_id = "15007105",
                            dest = "data/zenodo_prostate_600.csv",
                            force = FALSE) {
  if (file.exists(dest) && !force) {
    message("数据已存在，跳过下载: ", dest)
    return(TRUE)
  }
  dir.create(dirname(dest), recursive = TRUE, showWarnings = FALSE)

  api <- paste0("https://zenodo.org/api/records/", record_id)
  meta <- tryCatch(
    jsonlite::fromJSON(api, simplifyVector = FALSE),
    error = function(e) {
      message("无法访问 Zenodo API: ", conditionMessage(e))
      NULL
    }
  )
  if (is.null(meta)) return(FALSE)

  files <- meta$files
  csv_flags <- vapply(files, function(f) grepl("\\.csv$", f$key, ignore.case = TRUE), logical(1))
  if (!any(csv_flags)) {
    message("Zenodo 记录中未找到 CSV 文件。")
    return(FALSE)
  }
  target <- files[[which(csv_flags)[1]]]
  url <- target$links$self
  message("下载: ", target$key, " → ", dest)

  ok <- tryCatch({
    utils::download.file(url, destfile = dest, mode = "wb", quiet = FALSE)
    file.exists(dest) && file.size(dest) > 1000
  }, error = function(e) {
    message("下载失败: ", conditionMessage(e))
    FALSE
  })
  ok
}

# ---------- 模拟数据（结构与真实数据相似） ----------
make_simulated <- function(n = 600, seed = 20261102) {
  set.seed(seed)
  tibble(
    id            = paste0("P", sprintf("%04d", 1:n)),
    time_months   = pmin(rexp(n, 1/36), 60),
    bcr_status    = rbinom(n, 1, plogis(-1.2 + 0.4 * rnorm(n))),
    age           = round(rnorm(n, 65, 7)),
    psa_baseline  = rlnorm(n, 2.5, 0.8),
    gleason_score = sample(6:9, n, TRUE, prob = c(.2,.4,.3,.1)),
    surgical_margin = rbinom(n, 1, .25),
    pathologic_stage = sample(c("T2","T3/4"), n, TRUE),
    psa_3m  = rlnorm(n, -1.0, 0.7),
    psa_6m  = rlnorm(n, -1.2, 0.8),
    psa_12m = rlnorm(n, -1.3, 0.9)
  ) %>%
    mutate(bcr_status = ifelse(time_months >= 60, 0L, bcr_status))
}

# R/compute-dca-delta-nb.R —— DCA 提取与 ΔNB bootstrap
# ============================================================

# 从 dcurves::dca 对象提取净获益长表
extract_nb <- function(dca_obj) {
  as_tibble(dca_obj) %>%
    select(threshold, any_of(c("variable","nb","net_benefit"))) %>%
    rename_with(~"nb", any_of("net_benefit")) %>%
    filter(!is.na(nb))
}

# 计算 ΔNB（动态 − 静态），返回长表
compute_delta_nb <- function(nb_tbl, static_var = "static",
                              dynamic_vars = c("jm","lm")) {
  base <- nb_tbl %>% filter(variable == static_var) %>%
    select(threshold, nb_static = nb)
  map_dfr(dynamic_vars, function(v) {
    nb_tbl %>% filter(variable == v) %>%
      select(threshold, nb_dyn = nb) %>%
      left_join(base, by = "threshold") %>%
      mutate(delta_nb = nb_dyn - nb_static,
             rule = v) %>%
      select(rule, threshold, delta_nb)
  })
}

# Bootstrap ΔNB：对患者索引重抽样，用已拟合模型重新预测风险
# 说明：JM 模型不重拟合（MCMC 成本过高），仅反映患者抽样不确定性
bootstrap_delta_nb <- function(df, risk_cols, time_col, status_col,
                               time_horizon, thresholds,
                               n_boot = 200, seed = 20261102) {
  set.seed(seed)
  n <- nrow(df)
  out <- vector("list", n_boot)
  for (b in seq_len(n_boot)) {
    idx <- sample.int(n, n, replace = TRUE)
    d <- df[idx, ]
    dca_b <- tryCatch(
      dcurves::dca(
        as.formula(paste0("Surv(", time_col, ",", status_col, ") ~ ",
                          paste(risk_cols, collapse = " + "))),
        data = d, time = time_horizon, thresholds = thresholds
      ),
      error = function(e) NULL
    )
    if (is.null(dca_b)) next
    nb_b <- extract_nb(dca_b)
    # 统一列名为 static/jm/lm
    names(nb_b)[names(nb_b) == risk_cols[1]] <- "static"
    if (length(risk_cols) >= 2) names(nb_b)[names(nb_b) == risk_cols[2]] <- "jm"
    if (length(risk_cols) >= 3) names(nb_b)[names(nb_b) == risk_cols[3]] <- "lm"
    out[[b]] <- compute_delta_nb(nb_b, "static",
                                 intersect(c("jm","lm"), names(nb_b))) %>%
      mutate(boot = b)
  }
  bind_rows(out)
}

# ============================================================
# R/compute-cic.R —— 临床影响曲线（CIC）
# ============================================================

compute_cic <- function(time, status, risk, time_horizon,
                        thresholds = seq(0.05, 0.60, by = 0.01),
                        n_per = 1000) {
  stopifnot(length(time) == length(status), length(time) == length(risk))
  bind_rows(lapply(thresholds, function(pt) {
    high <- risk >= pt
    n_high <- sum(high)
    p_event <- 0
    if (n_high >= 5) {
      km <- survival::survfit(survival::Surv(time[high], status[high]) ~ 1)
      s <- summary(km, times = time_horizon)$surv
      p_event <- 1 - ifelse(length(s) == 0 || is.na(s), 0, s)
    }
    tibble(
      threshold         = pt,
      n_high_risk       = n_per * mean(high),
      n_high_risk_event = n_per * mean(high) * p_event,
      n_high_risk_false = n_per * mean(high) * (1 - p_event),
      unstable          = n_high < 20
    )
  }))
}

static_risk_at <- function(fit, df, tL, window) {
  sf <- survival::survfit(fit, newdata = df)
  s1 <- summary(sf, times = tL + window)$surv
  s0 <- summary(sf, times = tL)$surv
  as.numeric(1 - s1 / s0)
}

## ⚠️ 三个必须注意的执行细节

**第一，`CONFIG$var_map` 是唯一必须人工修改的地方。** Zenodo 数据集的实际列名无法在下载前确定，`01_data-prep.qmd` 会打印全部列名并在映射不匹配时发出 warning。在真实数据上，先单独跑 `01` 的前两个 chunk，核对列名后再继续。

**第二，路径 A（联合模型）的 `predict()` 接口是最脆弱的一环。** `03_dynamic-jm.qmd` 已用 `tryCatch` 包裹全部 JM 相关代码，拟合或预测失败时会打印信息并自动降级，`05`—`07` 通过 `intersect(c("risk_static","risk_jm","risk_lm"), names(d))` 动态适配可用规则。**如果 JM 在你的数据上不可用，整条流程仍能完整跑通，主分析以界标法为准**，这本身也是课题设计中“双路径”的价值所在。

**第三，Bootstrap ΔNB 的语义限制。** `bootstrap_delta_nb()` 对患者索引重抽样后**重新预测风险**，但**不重新拟合 JM 的 MCMC**（成本过高）。它反映的是患者抽样不确定性，而非全参数不确定性。这一限制应在方法部分明确写出，并在讨论中作为“证据确定性”的一部分加以说明。
