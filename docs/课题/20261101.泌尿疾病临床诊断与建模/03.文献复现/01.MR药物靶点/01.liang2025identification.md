PRACTICAL 前列腺癌 GWAS 在 OpenGWAS 中的数据集 ID 为 **`ieu-b-85`**（也可用 `ebi-a-GCST006085`，同一 PRACTICAL 汇总统计的镜像）。UKB-PPP pQTL 通过 **Synapse** 获取（`syn51364943`），需要注册账号并生成个人访问 token。

Synapse是可以下载UKB-PPP（UK Biobank Pharma Proteomics Project）数据的，但这需要遵循其特定的访问流程，并非完全匿名公开。

### 🔑 访问前提：注册与认证

要获取数据，你需要完成以下步骤来建立访问权限：

1.  **注册Synapse账户**：在`www.synapse.org`注册一个免费账户。
2.  **生成个人访问令牌（PAT）**：登录后，进入个人设置页面（`Profile:settings`），在“Personal Access Tokens”部分点击“Create new token”。**生成时务必勾选`view`和`download`权限**，并立即复制生成的令牌，因为它只会显示一次。
3.  **配置环境变量**：将你的令牌设置为环境变量`SYNAPSE_AUTH_TOKEN`，以便脚本或命令行工具能够自动认证。

完成这些步骤后，你才具备了从项目`syn51364943`下载文件的权限。

### 💻 数据下载方法

Synapse提供了多种下载方式，你可以根据需求选择：

#### 方法一：使用专用Python包 `ukbppp-dl`（推荐）
这是处理UKB-PPP这类大型数据集最高效的方式。该包专为从Synapse下载UKB-PPP文件设计，尤其适合只提取特定区域或显著性的pQTL数据，能有效管理内存和存储。

*   **核心功能**：它不会盲目下载整个区域文件（可能高达约**9TB**），而是可以**按蛋白逐个处理**，在下载过程中即时过滤和删除中间文件。运行该功能时，你需要的空闲磁盘空间可能**不超过1GB**。
*   **安装**：`pip install ukbppp-dl`。
*   **使用**：安装后，你可以用它的核心函数`keep_significant_qtls_from_region`来指定所需的蛋白、 ancestry（如欧洲人群）和显著性阈值，它会自动完成后续的下载、解压和过滤工作。

#### 方法二：Synapse官方客户端
如果你偏好更基础的控制，可以使用Synapse提供的官方客户端进行下载。

*   **Python客户端**：安装`synapseclient`包后，通过代码`synapseclient.Synapse().get(entity=synID, downloadLocation=...)`来下载指定ID的文件。
*   **命令行客户端**：安装后，可以使用`synapse get synXXXXXXX`命令来下载文件。

#### 方法三：网页界面手动下载
对于少量、特定的文件，你也可以直接通过浏览器访问项目页面（`https://www.synapse.org/Synapse:syn51364943`），在文件列表中手动点击下载。但对于大规模数据，这种方式效率较低。

### ⚠️ 关键注意事项
*   **替代路径不可用**：尽管AWS Open Data Registry上列有UKB-PPP，但实际匿名访问会返回`AccessDenied`错误。**Synapse是目前数据所有者提供的唯一有效下载途径**。
*   **个体级数据限制**：需要注意的是，通过Synapse公开获取的是**汇总统计（Summary Statistics）**，如pQTL结果。UKB的**个体级基因型和蛋白表达数据**受更严格的管控，需要向UK Biobank提出正式申请（如申请号19655）并通过审批，不能直接从Synapse下载。

## 五、工具变量筛选与 MR

以下以 **SCP2** 为例。如果你从 UKB-PPP 下载的是 SCP2 的 cis-pQTL 文件（`SCP2.tsv.gz`），先读入并筛选工具变量。

```r
library(data.table)
library(dplyr)

# ---- 5.1 读入 SCP2 cis-pQTL ----
scp2_raw <- fread("SCP2.tsv.gz", header = TRUE)

# 列名映射（根据 UKB-PPP 实际列名调整）
scp2_exp <- scp2_raw %>%
  transmute(
    SNP   = rsid,
    beta  = beta,
    se    = se,
    pval  = pval,
    eaf   = maf,
    effect_allele = alt,
    other_allele  = ref,
    exposure = "SCP2",
    samplesize = N
  )

# ---- 5.2 工具变量筛选：cis ±1 Mb + P<5e-8 + LD clumping ----
# 假设 SCP2 基因坐标已知（GRCh38: chr1:53,000,000-53,200,000 附近，按实际调整）
# 若 pQTL 文件本身已限定 cis 区域，可跳过坐标过滤
scp2_sig <- scp2_exp %>% filter(pval < 5e-8)

# LD clumping（通过 OpenGWAS API，需 token；r2=0.001, kb=10000）
scp2_iv <- ld_clump(
  dat = scp2_sig,
  clump_r2 = 0.001,
  clump_kb = 10000,
  pop = "EUR"
)

# ---- 5.3 F 统计量 ----
# 若只有汇总数据，F ≈ beta^2 / se^2（单 SNP 近似）
scp2_iv <- scp2_iv %>% mutate(F_stat = (beta / se)^2)
scp2_iv <- scp2_iv %>% filter(F_stat > 10)

cat("保留的 IV 数量:", nrow(scp2_iv), "\n")
```

```r
# ---- 5.4 提取结局数据并 harmonise ----
```

## 六、贝叶斯共定位

对每个通过 FDR 的蛋白，使用 **coloc** 检验 pQTL 与前列腺癌 GWAS 是否共享因果变异。原文阈值：**PPH4 > 0.8** 为强共定位；**PPH3 + PPH4 ≥ 0.8** 为中等证据。

```r
library(coloc)

# ---- 6.1 准备共定位输入：蛋白 cis 区域全部 SNP（不仅限于工具变量） ----
# 从 SCP2 原始 pQTL 中取基因 ±1 Mb 内的所有 SNP
# 前列腺癌结局需在同一区域提取对应 SNP 的 beta/se
# 以下假设已得到 region_snps（含 SNP, beta_exp, se_exp, beta_out, se_out, maf, N_exp, N_out）

run_coloc <- function(df, protein_name,
                      p12 = 1e-5,
                      p1 = 1e-4, p2 = 1e-4) {
  res <- coloc.abf(
    dataset1 = list(
      snp     = df$SNP,
      beta    = df$beta_exp,
      varbeta = df$se_exp^2,
      type    = "quant",
      N       = df$N_exp[1],
      MAF     = df$maf
    ),
    dataset2 = list(
      snp     = df$SNP,
      beta    = df$beta_out,
      varbeta = df$se_out^2,
      type    = "cc",
      N       = df$N_out[1],
      s       = 79148 / (79148 + 61106)   # PRACTICAL 病例比例
    ),
    p12 = p12
  )
  summary_df <- as.data.frame(res$summary)
  summary_df$protein <- protein_name
  summary_df$PPH4_strong <- summary_df$PP.H4.abf > 0.8
  summary_df$PPH34_moderate <- (summary_df$PP.H3.abf + summary_df$PP.H4.abf) >= 0.8
  return(summary_df)
}
```

## 七、MR-PheWAS（安全性扫描）

原文使用 **FinnGen R10 的 2,408 个结局**，以 cis-pQTL 为暴露，逐个结局运行 MR，FDR < 0.05 判定显著。以下给出**循环框架**；由于 FinnGen 结局数量大，实际操作中需要先获取 FinnGen R10 的 endpoint 列表和汇总统计文件。

```r
# 假设已获取 finngen_r10_endpoints（含 endpoint 代码和文件路径）
# 以及 scp2_iv（SCP2 的工具变量）

phewas_results <- list()

for (i in seq_len(nrow(finngen_r10_endpoints))) {
  ep <- finngen_r10_endpoints$endpoint[i]
  path <- finngen_r10_endpoints$file_path[i]

  # 读入 FinnGen endpoint 汇总统计（仅提取工具变量 SNP）
  finngen_dat <- fread(path, select = c("#chrom", "pos", "ref", "alt", "rsids", "beta", "sebeta", "pval", "af_alt"))
  finngen_dat <- finngen_dat[rsids %in% scp2_iv$SNP]

  if (nrow(finngen_dat) == 0) next

  # 格式化
  out_fmt <- format_data(
    finngen_dat,
    type = "outcome",
    snp_col = "rsids",
    beta_col = "beta",
    se_col = "sebeta",
    effect_allele_col = "alt",
    other_allele_col = "ref",
    eaf_col = "af_alt",
    pval_col = "pval"
  )

  dat_ph <- harmonise_data(scp2_iv, out_fmt, action = 2)
  if (nrow(dat_ph) == 0) next

  mr_ph <- mr(dat_ph, method_list = c("mr_wald_ratio", "mr_ivw"))
  mr_ph$endpoint <- ep
  phewas_results[[ep]] <- mr_ph
}

phewas_all <- bind_rows(phewas_results)
phewas_all$pval_fdr <- p.adjust(phewas_all$pval, method = "BH")
phewas_sig <- phewas_all %>% filter(pval_fdr < 0.05)
```

## 九、扩展模块：分子动力学模拟（原文未包含，补齐“完整流程”）

对接给出的是静态结合能，MD 用于检验复合物在溶液中的稳定性。以下以 **SCP2–β-Amyrone** 为例，使用 **OpenMM** 进行 100 ns 模拟，并计算 RMSD、RMSF 和 MM-PBSA 结合自由能。

```python
# ---- 9.1 复合物准备 ----
# 从 Vina 输出中取 SCP2–β-Amyrone 的最优构象，将蛋白和配体合并为一个 PDB
# 配体参数化：使用 OpenMM 的 GAFF 或 OpenFF 工具包
# 以下假设已得到 complex.pdb（蛋白 + 配体）

from openmm.app import PDBFile, ForceField, Modeller, Simulation
from openmm import LangevinMiddleIntegrator, Platform, unit
from openmm.app import PME, HBonds

pdb = PDBFile('complex.pdb')
forcefield = ForceField('amber14-all.xml', 'amber14/tip3pfb.xml')
modeller = Modeller(pdb.topology, pdb.positions)
modeller.addHydrogens(forcefield)
modeller.addSolvent(forcefield, padding=1.0*unit.nanometer)

system = forcefield.createSystem(
    modeller.topology,
    nonbondedMethod=PME,
    nonbondedCutoff=1.0*unit.nanometer,
    constraints=HBonds
)

integrator = LangevinMiddleIntegrator(
    300*unit.kelvin, 1/unit.picosecond, 0.002*unit.picoseconds
)
simulation = Simulation(modeller.topology, system, integrator)
simulation.context.setPositions(modeller.positions)

# 能量最小化
simulation.minimizeEnergy()

# 100 ns MD（可根据算力调整）
simulation.reporters.append(
    XTCReporter('traj.xtc', 1000)   # 每 1000 步保存一帧
)
simulation.reporters.append(
    StateDataReporter('md.log', 1000, step=True, potentialEnergy=True, temperature=True)
)
simulation.step(50_000_000)   # 100 ns / 0.002 ps = 5e7 步
```

## 十、复现时的四个关键检查点

**第一，暴露端坐标。** UKB-PPP pQTL 文件可能已经预过滤到 cis 区域，也可能包含全基因组 SNP。如果文件是全体 SNP，必须先按基因坐标（±1 Mb）过滤，再做 P < 5×10⁻⁸ 和 LD clumping。原文的 cis 定义是“基因 ±1 Mb”。

**第二，F 统计量的计算口径。** 原文写的是 \(F = R^2(n-k-1)/k(1-R^2)\)，但在仅有汇总统计时，更常用的是 \(F \approx \beta^2 / SE^2\)。两种口径在单 SNP 时近似等价；多 SNP 时应以 \(R^2\) 口径为准。本文代码采用 \(\beta^2/SE^2\) 近似，结果偏保守，可以保留 F > 10 的 SNP。

**第三，共定位的先验设置。** 原文未明确报告 coloc 的 `p12`。默认 `p12 = 1e-5` 是稳妥选择；如果 pQTL 与 GWAS 的信号强度差异很大，`p12` 可能需要调至 `1e-6` 或 `1e-4`，并在敏感性分析中报告 PPH4 的变化。原文阈值 **PPH4 > 0.8** 比常见 coloc 研究的 0.7–0.75 更严格。

**第四，对接的重复性。** Vina 的随机种子、盒子中心和 exhaustiveness 会改变排名。β-Amyrone 在原文中同时结合 SCP2 和 C5，复现时如果 Top 1 化合物不同，不一定是流程错误——先检查 SCP2 的 PDB 结构是否与原文一致（原文从 PDB 检索高分辨率结构，但未在正文中给出 PDB ID，需在补充材料中确认）。如果 PDB 结构不同，对接结果的可比性有限。
