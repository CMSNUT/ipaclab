::: info 研究背景
  GSK3β介导的胰岛素信号紊乱参与2型糖尿病发病，黄芪‑党参药对具有降糖作用。然而，该药对靶向GSK3β干预2型糖尿病的具体机制仍然知之甚少。
:::

::: note 方法特点
- 细胞动物：无体内外实验，开展黄芪‑党参药对计算药理学研究；

- 计算技术：网络药理学、PPI网络、GO/KEGG富集、分子对接、分子动力学、丙氨酸扫描、DFT理论计算
:::

::: details 摘要
黄芪和党参因其显著的降糖药理作用而被广泛应用于中药治疗糖尿病。研究表明，黄芪党参中的活性化合物可能通过调节胰岛素受体（IRSP）信号通路发挥其降血糖作用。本研究通过网络药理学结合 DFT 理论计算、分子对接、分子动力学模拟及丙氨酸扫描突变技术，进一步系统探讨了 rhamnolitrin 和叶酸作为调节黄芪党参对 IRSP 的关键活性成分在 2 型糖尿病（T2DM）中的协同作用机制。结果表明 GSK3 β 是鼠李糖苷和叶酸发挥抗糖尿病作用的关键靶点。随后的分子对接和分子动力学模拟证实，本研究所选的两种活性化合物均能与 GSK3 β 蛋白稳定结合。进一步的丙氨酸扫描诱变实验验证了配体 - 受体相互作用中关键氨基酸残基的重要性。最后，DFT 理论计算详细阐明了核心成分（rhamnolitrin 和 folic acid）与靶蛋白 GSK3 β 之间的结合机制。本研究不仅揭示了黄芪党参治疗 2 型糖尿病的分子机制，为其临床应用提供了理论依据，也为新型抗糖尿病药物的研发提供了潜在的分子靶点。
:::

### 分子对接

| 项目 | 内容 |
| :--- | :--- |
| **研究目的** | 模拟配体与受体蛋白的结合过程，寻找最佳结合构象。 |
| **研究内容** | 对受体蛋白进行预处理，定义活性口袋，进行半柔性对接，筛选最佳构象用于后续动力学模拟。 |
| **方法** | 1. 修复缺失残基、优化质子化、去水；<br>2. 定义配体 10 Å 范围内为活性口袋进行 CDOCKER 对接；<br>3. 基于能量打分筛选最佳结合模式。 |
| **软件/工具** | **Discovery Studio 2019**（[https://www.3ds.com/products/biovia/discovery-studio](https://www.3ds.com/products/biovia/discovery-studio)）；引用格式建议：BIOVIA Discovery Studio [Version 2019], Dassault Systèmes, San Diego, CA, USA.<br>CDOCKER 模块（内置于 Discovery Studio） |
| **数据库/集** | 无。 |

### 分子动力学模拟

| 项目 | 内容 |
| :--- | :--- |
| **研究目的** | 在原子水平上研究鼠李糖苷、叶酸与靶蛋白 GSK3β 的结合稳定性及动态构象变化。 |
| **研究内容** | 构建溶剂化系统，进行能量优化、系统平衡及 100 ns 的正式动力学模拟。 |
| **方法** | 1. TIP3P 水模型，0.154 M 离子浓度，OPLS3e 力场；<br>2. 最速下降法（5000步）+ 共轭梯度法（2000步）能量优化；<br>3. NVT 系综（100ps, 300K）和 NPT 系综（100ps, 1bar）平衡；<br>4. 100ns 正式模拟（步长 2fs，每 10ps 采样）。 |
| **软件/工具** | **Schrödinger 2024**（[https://www.schrodinger.com](https://www.schrodinger.com)）；引用格式建议：Schrödinger Release 2024: Maestro, Desmond, Schrödinger, LLC, New York, NY, 2024. |
