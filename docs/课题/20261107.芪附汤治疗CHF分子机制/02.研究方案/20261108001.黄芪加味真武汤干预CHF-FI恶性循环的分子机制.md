### 📄 一、 摘要（Abstract）骨架

> **Background（背景）:**
> 慢性心力衰竭（CHF）与虚弱（Frailty）在临床上高度共存，二者互为因果，形成相互加剧的“恶性循环”。黄芪加味真武汤在干预心衰阳虚证中具有临床基础，但其能否精准靶向这一双向因果界面尚不明确。传统的网络药理学多依赖疾病关联数据库，无法区分“相关性”与“因果性”，更无法界定靶点在恶性循环中的拓扑位置。

> **Methods（方法）:**
> 本研究整合多组学与计算模拟策略：① **表型因果确立**：利用GWAS汇总数据，通过双向孟德尔随机化（MR）确认CHF与Frailty的互为因果关系。② **因果靶点获取与分层**：以cis-pQTL为工具变量进行MR及共定位分析（PP.H4 > 0.7），筛选对双疾病均有因果效应的蛋白；进而通过两步MR与多变量MR（MVMR），将靶点精细划分为**共享上游靶点**（源头驱动）、**单向中介靶点**（单向恶化传导）和**双向中介靶点**（正反馈核心枢纽）。③ **复方靶点交集**：基于TCMSP等数据库及ADMET过滤获取黄芪加味真武汤活性成分及预测靶点，与上述三类因果靶点取交集。④ **网络与转录组验证**：对交集靶点进行PPI、MCODE模块挖掘、GO/KEGG富集及TF-miRNA-mRNA网络构建；利用GSE57338（心衰心肌）与GSE1428（骨骼肌衰老）进行差异表达及GSVA验证。⑤ **分子模拟**：对核心因果靶点与活性成分进行分子对接与分子动力学（MD）模拟。

> **Results（结果）:**
> *(留白待填，建议按以下顺序撰写)*
> 1. 双向MR揭示的因果效应量（OR及P值）。
> 2. pQTL-MR与共定位鉴定的候选因果蛋白数量，以及分层出的双向中介、单向中介、共享上游靶点的具体数量。
> 3. 复方靶点与三类因果靶点的交集情况（重点说明复方主要覆盖了哪一类靶点）。
> 4. GEO验证结果（交集靶点在疾病状态下的表达差异及GSVA活性变化）。
> 5. 对接与MD结果（核心成分与关键靶点的结合稳定性）。

> **Conclusions（结论）:**
> 本研究以双向因果靶点替代传统关联靶点，构建了“共享上游—单向中介—双向中介”的因果分层框架。首次从因果拓扑的角度解析了黄芪加味真武汤“异病同治”的潜在分子机制：其可能通过干预双向中介靶点切断正反馈循环、阻断单向中介靶点截断恶化传导，并改善共享上游靶点实现共病源头的双重干预。本研究为中医药干预复杂共病提供了可检验的计算假说与全新范式。

### 📖 二、 引言（Introduction）骨架（五段式）

**第一段：临床现状与病理逻辑（抛出“恶性循环”）**
*   **内容**：指出CHF与虚弱（Frailty）是老年医学和心血管领域的两大难题，两者在流行病学上高度共病。描述临床现象：心衰导致活动耐力下降引发虚弱，而虚弱又会加重心衰恶化，二者形成互相驱动的“恶性循环”。指出**打破这一循环是共病干预的关键**。
*   **目的**：确立研究的临床价值与疾病背景。

**第二段：遗传学证据与传统靶点发现的局限（引出双向MR）**
*   **内容**：引出近期双向MR研究已证实CHF与Frailty在遗传层面存在互为因果关系（引用Wang et al., 2025）。然而，目前关于心衰共病的基础研究仍多依赖GeneCards等关联数据库。指出其缺陷：关联基因只代表“相关”，不提供“因果驱动力”，无法解释“恶性循环”的病理机制。
*   **目的**：说明使用双向MR结合pQTL寻找因果蛋白的必要性。

**第三段：因果分层的必要性与方法学创新（引出三类靶点）**
*   **内容**：单凭pQTL-MR找出的因果蛋白仍是一个扁平的清单。在互为因果的恶性循环中，不同蛋白的拓扑地位不同：有的独立驱动两病（共享上游），有的只负责单向传导（单向中介），有的位于循环正中心（双向中介）。引入两步MR与MVMR技术，说明如何将因果蛋白进行“分层”。
*   **目的**：这是本文最核心的创新点，必须在引言中浓墨重彩地论述。

**第四段：黄芪加味真武汤的研究现状与未解之谜（引出方剂）**
*   **内容**：简述黄芪加味真武汤（温阳利水、益气健脾）在临床治疗心衰的有效性。但同时指出，以往关于真武汤或黄芪的网络药理学研究，往往直接与全基因组疾病关联靶点对接，得出的机制较为宽泛（如泛泛的PI3K-Akt通路）。**缺乏“方剂成分-精确覆盖双向因果节点”的深度解析**。
*   **目的**：明确本研究的方剂特色，并在已有文献的基础上指出空白。

**第五段：研究目的与科学假说**
*   **内容**：明确本研究的科学假说：黄芪加味真武汤并非泛泛干预，而是精准靶向了CHF-Frailty的因果界面上。概括研究策略：整合双向MR、pQTL-MR、因果分层、网络药理学、GEO验证与分子模拟，旨在阐明黄芪加味真武汤靶向“恶性循环”潜在靶点的物质基础与机制，为临床“异病同治”提供精准的靶标线索。
*   **目的**：收尾，统摄全文。

【目的】
慢性心力衰竭与虚弱常伴随发生，二者叠加显著升高不良预后风险，但二者是否存在因果恶性循环尚不明确；传统网络药理学靶点假阳性较高。本研究旨在借助遗传因果推断联合网络药理学，识别黄芪加味真武汤靶向慢性心力衰竭-虚弱恶性循环的潜在靶点，阐释其潜在分子机制。

【方法】

### 二、引言（Introduction）骨架，分4段，层层递进，严格扣题
#### 第1段：临床问题（临床痛点）
慢性心力衰竭是老年人群高发心血管疾病，虚弱是老年人群重要的老年综合征。慢性心力衰竭与虚弱共病十分常见，二者共存会放大再入院、全因死亡、功能衰退等不良结局风险。既往观察性研究多报道二者存在相关性，但**相关性无法区分因果、混杂与反向因果**；目前尚不清楚二者是否形成相互促进的恶性循环，限制了共病干预靶点的识别与治疗策略开发。

#### 第2段：现有研究局限 + 中医药切入点（为什么选黄芪加味真武汤）
真武汤是温阳利水经典方剂，黄芪加味真武汤在临床中用于慢性心力衰竭的治疗，可改善心衰患者水肿、乏力、活动耐量下降等症状，对虚弱相关表型也有改善潜力。但该复方的作用靶点与分子机制尚不清晰。
传统网络药理学仅基于蛋白数据库预测靶点，缺乏因果证据，大量预测靶点为无疾病因果效应的假阳性靶点，难以区分靶点是否真实参与疾病发生发展。

#### 第3段：方法学优势 + 本研究科学思路（扣题核心：双向MR + 因果分层）
孟德尔随机化以遗传变异为工具变量，可降低混杂、反向因果干扰，用于推断暴露与结局的因果关系。
本研究首先利用**双向表型孟德尔随机化**检验慢性心力衰竭与虚弱之间是否存在双向因果，验证恶性循环前提；进一步采用顺式pQTL MR+共定位筛选同时驱动两种表型的共享蛋白；再通过中介MR实施**因果分层分析**，将共享蛋白分为两类：介导CHF与虚弱之间因果传递的中介因子、独立驱动两种表型的共享上游调控因子。
随后结合网络药理学挖掘黄芪加味真武汤活性成分靶点，对接分层后的因果靶点，规避传统网络药理学无因果支撑的缺陷。

#### 第4段：研究目的、科学假设、研究意义（收尾，对齐标题）
**研究假设**：黄芪加味真武汤可通过靶向部分中介因子或共享上游因果蛋白，干预慢性心力衰竭-虚弱的恶性循环。
本研究拟整合双向孟德尔随机化、因果分层分析与网络药理学，挖掘黄芪加味真武汤靶向慢性心力衰竭-虚弱恶性循环的潜在分子机制。本研究旨在为该复方治疗慢性心力衰竭-虚弱共病提供具备遗传因果证据的机制假说，为后续实验验证、靶点开发提供候选分子。

## 初稿样本(DB)
黄芪加味真武汤靶向慢性心力衰竭-虚弱恶性循环的潜在分子机制：一项整合双向孟德尔随机化与因果分层分析的网络药理学研究
### 摘要
慢性心力衰竭与虚弱共病在老年人群中十分常见，二者共存会显著升高再入院、功能衰退及全因死亡等不良事件风险。现有观察性研究仅报道二者存在相关性，难以区分混杂因素与反向因果效应，慢性心力衰竭与虚弱之间是否存在相互促进的恶性循环尚不明确；同时传统网络药理学直接基于数据库预测靶点，缺乏疾病因果证据支撑，假阳性较高，限制了复方机制阐释的可信度。本研究旨在整合双向孟德尔随机化、因果分层分析与网络药理学方法，识别黄芪加味真武汤靶向慢性心力衰竭-虚弱恶性循环的潜在分子靶点，阐释其潜在作用机制。方法：首先开展表型-表型双向孟德尔随机化分析，验证慢性心力衰竭与虚弱之间的双向因果关系；其次采用顺式蛋白数量性状位点（cis-pQTL）孟德尔随机化联合遗传信号共定位分析，筛选同时对两种表型存在因果效应的共享蛋白；进一步借助中介孟德尔随机化开展因果分层分析，将共享因果蛋白划分为中介因子与共享上游调控因子；运用网络药理学挖掘黄芪加味真武汤的活性成分及其潜在作用靶点，将方药预测靶点与分层后的因果蛋白靶点取交集，获得复方可靶向的候选分子，并开展GO、KEGG功能富集分析。结果：双向孟德尔随机化结果证实慢性心力衰竭与虚弱之间存在双向因果效应，支持二者形成恶性循环的假说；顺式pQTL孟德尔随机化联合共定位筛选得到若干共享因果蛋白；中介孟德尔随机化因果分层将候选蛋白分为中介因子与共享上游调控因子；网络药理学交集得到黄芪加味真武汤可靶向的因果靶点，富集通路主要涉及炎症调控、心肌重构、能量代谢、衰老相关信号通路等。结论：本研究整合双向孟德尔随机化、因果分层分析与网络药理学，识别了黄芪加味真武汤靶向慢性心力衰竭-虚弱恶性循环的潜在分子靶点。本研究区分了中介因子与共享上游调控因子两类因果蛋白，为理解黄芪加味真武汤干预慢性心力衰竭-虚弱共病提供了具备遗传因果证据支撑的机制假说，可为后续基础实验验证与临床转化研究提供候选方向。本研究属于计算机整合分析，所得结论尚需体内外实验进一步验证。

**关键词**：黄芪加味真武汤；慢性心力衰竭；虚弱；恶性循环；孟德尔随机化；顺式pQTL；中介分析；网络药理学

### 引言
慢性心力衰竭是心血管疾病的终末期阶段，在老年人群中患病率居高不下，显著降低患者生活质量、增加医疗负担。虚弱是一种以生理储备下降、应激耐受能力减退为核心特征的老年综合征。临床队列研究显示，慢性心力衰竭患者合并虚弱的比例显著高于普通人群，二者共病后，患者再入院、跌倒、失能、全因死亡的风险较单一疾病患者进一步升高。目前大量观察性流行病学研究已经报道慢性心力衰竭与虚弱存在显著关联，但相关性不等同于因果关系，观察性研究难以规避混杂因素、反向因果的干扰，无法回答慢性心力衰竭是否会因果促进虚弱发生、虚弱是否反过来加重慢性心力衰竭这一核心问题。慢性心力衰竭与虚弱之间是否存在相互促进的恶性循环，至今缺少因果层面的证据，这也阻碍了共病干预靶点的精准识别与治疗策略的开发。

真武汤是中医温阳利水的经典方剂，常用于水饮凌心证心力衰竭的治疗；黄芪加味真武汤在原方基础上增加黄芪，兼顾补气行水，临床常用于慢性心力衰竭患者，可改善患者水肿、乏力、活动耐量下降等症状，对虚弱相关体能衰退、耐力下降等表型也具备一定改善潜力。然而，黄芪加味真武汤发挥治疗效应的分子靶点与调控机制尚不清晰。既往针对该复方的机制研究多采用传统网络药理学方案，直接依托数据库预测化合物靶点，这类靶点仅为蛋白结合预测结果，缺少与疾病表型之间的因果证据，大量预测靶点并未参与慢性心力衰竭或虚弱的发生发展，存在较高假阳性，导致机制假说说服力有限。

孟德尔随机化以遗传变异作为工具变量，利用基因型在受孕时随机分配的特点，有效降低混杂偏倚与反向因果干扰，适合推断暴露与结局之间的因果关联。本研究首先采用表型双向孟德尔随机化检验慢性心力衰竭与虚弱之间是否存在双向因果，验证恶性循环的前提；进一步利用顺式pQTL孟德尔随机化联合共定位分析，筛选能够同时因果影响慢性心力衰竭与虚弱的共享蛋白；在此基础上开展中介孟德尔随机化实施因果分层分析，将共享蛋白划分为两类：介导慢性心力衰竭与虚弱之间因果传递的中介因子、独立驱动两种表型但不参与表型间效应传递的共享上游调控因子。随后结合网络药理学挖掘黄芪加味真武汤活性成分及其潜在靶点，对接分层后的因果靶点，克服传统网络药理学靶点缺少因果支撑的短板。

本研究的科学假设为：黄芪加味真武汤可通过靶向部分中介因子或共享上游因果蛋白，干预慢性心力衰竭-虚弱之间的恶性循环。因此，本研究拟整合双向孟德尔随机化与因果分层分析的网络药理学策略，探索黄芪加味真武汤靶向慢性心力衰竭-虚弱恶性循环的潜在分子机制，为该复方治疗慢性心力衰竭-虚弱共病提供具有遗传因果证据支撑的机制假说，为后续靶点验证与新药开发提供参考。

### 材料与方法
#### 2.1 数据来源
慢性心力衰竭、虚弱的全基因组关联研究（GWAS）汇总数据均来自公开数据库，纳入研究人群为欧洲祖先个体，排除亲缘关系重叠样本，获取表型对应的SNP效应值、标准误、P值等汇总信息。顺式蛋白数量性状位点（cis-pQTL）汇总数据集同样选用公开队列，仅保留顺式调控区域的遗传变异作为工具变量，使用连锁不平衡（LD）聚类（LD clumping）筛选独立工具SNP，设定r²阈值与窗口大小，剔除高度连锁不平衡的变异。黄芪加味真武汤所含化合物从TCMSP、BATMAN-TCM数据库检索获取，收集方剂中所有组分的化学信息。本研究所有分析均基于已公开的汇总GWAS数据，无需伦理审批。

#### 2.2 表型-表型双向孟德尔随机化分析
本部分分析目的为检验慢性心力衰竭与虚弱之间是否存在双向因果效应，验证恶性循环的前提。设置两组分析方向：① 暴露为慢性心力衰竭，结局为虚弱；② 暴露为虚弱，结局为慢性心力衰竭。本研究选择逆方差加权法（IVW）作为主分析模型；敏感性分析包括MR-Egger回归、加权中位数法、MR-PRESSO离群值校正、留一法分析；同时采用Cochran Q检验评估工具变量异质性，Steiger定向检验判断因果方向，排除反向因果偏倚。当IVW结果提示效应显著，且多项敏感性分析结果稳定时，认为存在因果证据。

#### 2.3 顺式pQTL孟德尔随机化联合共定位筛选共享因果蛋白
以蛋白丰度作为暴露，分别以慢性心力衰竭、虚弱作为结局开展顺式pQTL孟德尔随机化分析，MR模型、敏感性分析方案同2.2。同时开展遗传信号共定位分析，采用coloc或SMR+HEIDI检验区分连锁不平衡信号与真实因果信号。共定位判定标准为H4后验概率＞0.7且HEIDI检验P＞0.01，提示顺式pQTL信号与疾病GWAS信号为同一因果信号。纳入标准：该蛋白在蛋白→慢性心力衰竭、蛋白→虚弱两条孟德尔随机化分析中均满足MR显著且共定位阳性，最终得到共享因果蛋白候选集。

#### 2.4 中介孟德尔随机化因果分层分析
对上述筛选得到的每一个共享因果蛋白M，分别开展双向中介孟德尔随机化检验：通路1：暴露=慢性心力衰竭，中介变量=M，结局=虚弱；通路2：暴露=虚弱，中介变量=M，结局=慢性心力衰竭。中介MR输出总效应、直接效应、间接效应以及中介比例。分层判定标准：若至少一条通路的间接效应显著，则该蛋白判定为中介因子；若两条通路的间接效应均无统计学意义，且该蛋白依然独立因果影响慢性心力衰竭与虚弱，则归类为共享上游调控因子。本步骤即为文中所述因果分层分析。

#### 2.5 黄芪加味真武汤网络药理学分析
从TCMSP数据库筛选黄芪加味真武汤活性化合物，筛选标准设定口服生物利用度（OB）≥30%、类药性（DL）≥0.18。利用靶点预测数据库获取活性成分对应的潜在靶标，剔除非人源靶点，对基因名称进行标准化，依据HGNC数据库统一基因符号。将标准化后的方药靶点与分层得到的因果蛋白靶点（中介因子+共享上游调控因子）取交集，得到黄芪加味真武汤可靶向的因果靶点。将交集靶点导入STRING数据库构建蛋白互作（PPI）网络，导入Cytoscape软件进行可视化，根据拓扑参数筛选核心Hub靶点，区分中介来源Hub与上游来源Hub。随后开展GO与KEGG富集分析，校正后FDR作为富集条目筛选阈值。

#### 2.6 统计分析
本研究使用R语言开展所有统计分析，核心R包包括TwoSampleMR、coloc、ggplot2等；多重检验采用FDR校正，所有检验均为双侧检验。PPI网络可视化采用Cytoscape。

### 结果
#### 3.1 表型双向孟德尔随机化结果
慢性心力衰竭作为暴露、虚弱作为结局的IVW分析提示慢性心力衰竭可因果升高虚弱发生风险；虚弱作为暴露、慢性心力衰竭作为结局的IVW分析提示虚弱同样可因果升高慢性心力衰竭发病风险。Cochran Q检验提示工具变量异质性水平可控，MR-Egger截距检验未提示显著水平多效性，MR-PRESSO、留一法分析结果稳定，Steiger定向检验支持预设因果方向。上述结果提示慢性心力衰竭与虚弱存在双向因果效应，支持二者形成恶性循环的假说。本部分配套图表包括MR散点图、效应森林图、漏斗图、留一法分析图。

#### 3.2 cis-pQTL MR与共定位筛选共享因果蛋白
经顺式pQTL孟德尔随机化与共定位初步筛选，得到满足蛋白→慢性心力衰竭显著且共定位阳性的蛋白，以及蛋白→虚弱显著且共定位阳性的蛋白；取二者交集，最终获得XX个同时对两种表型存在因果效应的共享因果蛋白。汇总表格展示各蛋白的效应值、FDR、H4后验概率、HEIDI检验P值，作为后续中介分层的候选蛋白池。

#### 3.3 中介MR因果分层结果
对XX个共享因果蛋白逐一开展双向中介孟德尔随机化分析，分层结果显示：其中XX个蛋白判定为中介因子，分别在慢性心力衰竭→蛋白→虚弱、虚弱→蛋白→慢性心力衰竭通路中存在显著间接效应；剩余XX个蛋白为共享上游调控因子，其对慢性心力衰竭、虚弱具备独立因果效应，但两条通路的间接效应均无统计学意义。表格汇总所有蛋白的直接效应、间接效应、中介比例。结果提示共享因果蛋白可划分为两类功能角色，在慢性心力衰竭-虚弱恶性循环中发挥不同作用模式。

#### 3.4 黄芪加味真武汤活性成分与靶点交集
共筛选得到黄芪加味真武汤活性化合物XX个，预测得到潜在靶点XX个，经HGNC标准化去重后得到靶点XX个。将方药靶点与分层后的因果蛋白靶点取交集，获得XX个黄芪加味真武汤可靶向的因果靶点，其中包含中介型靶点XX个，共享上游型靶点XX个。构建PPI网络，根据度值、介数中心性等拓扑指标筛选得到核心Hub靶点。

#### 3.5 功能富集分析结果
GO富集结果提示交集靶点主要富集于炎症反应调控、细胞凋亡、氧化应激、细胞能量代谢、细胞衰老等生物学过程；KEGG通路富集提示靶点集中于炎症信号通路、心肌重构相关通路、衰老调控通路、代谢调节通路等。上述通路与慢性心力衰竭心肌损伤、心功能减退、虚弱生理储备下降的病理过程高度相关。富集结果提示黄芪加味真武汤可能通过调控上述通路，靶向中介因子与共享上游因子，干预慢性心力衰竭-虚弱恶性循环。

#### 3.6 整合机制网络图
构建整合机制示意图，直观展示黄芪加味真武汤活性成分、中介靶点、共享上游靶点、慢性心力衰竭-虚弱双向循环之间的调控关系，作为Graphical Abstract。

### 讨论
本研究首先通过双向表型孟德尔随机化证实慢性心力衰竭与虚弱存在双向因果关系，验证了恶性循环假说；进一步利用顺式pQTL孟德尔随机化联合共定位筛选共享因果蛋白，并依托中介孟德尔随机化完成因果分层，将候选蛋白划分为中介因子与共享上游调控因子；结合网络药理学挖掘黄芪加味真武汤活性成分及其靶点，识别出复方可靶向的因果靶点。区别于传统网络药理学无因果支撑的靶点预测，本研究先通过遗传因果推断锁定疾病相关靶点，再对接复方成分，有效降低传统网络药理学的假阳性风险，为阐释黄芪加味真武汤的作用机制提供了更高可信度的假说。

本研究因果分层分析得到两类不同功能的靶点，二者干预价值存在明显差异。中介因子是慢性心力衰竭与虚弱因果传递链条上的中间节点，慢性心力衰竭通过改变该类蛋白丰度促进虚弱，虚弱也可通过该类蛋白加重慢性心力衰竭。靶向中介因子，能够直接打断慢性心力衰竭与虚弱之间的效应传递通路，阻断恶性循环的流转。富集结果提示中介靶点多集中于炎症、氧化应激、衰老相关通路，与既往心衰、虚弱的机制研究报道吻合。共享上游调控因子可独立驱动慢性心力衰竭与虚弱的发生，但不参与两种表型之间的因果传递。靶向该类靶点能够同时降低两种疾病的发病风险，但无法直接阻断慢性心力衰竭与虚弱之间的相互转化通路。两类靶点互补，共同构成黄芪加味真武汤干预共病的候选分子基础。

黄芪加味真武汤由真武汤加黄芪组成，原方真武汤温阳利水，改善水饮凌心所致水肿、喘促；加黄芪增强补气行水之功，契合心衰患者阳气亏虚、水湿内停、气虚乏力的病机。临床观察提示该方可改善心衰患者心功能、水肿及体能衰弱表现，但既往机制研究缺少因果层面支撑。本研究识别的核心活性成分如黄芪甲苷、芍药苷、附子生物碱等，既往基础研究已报道具备抗炎、抗心肌重构、改善能量代谢等作用，与本研究富集通路相互印证。相较于既往同方剂网络药理学研究，本研究新增因果推断与分层策略，对靶点的功能角色进行区分，机制叙事更加精细。

本研究存在如下局限性：第一，研究所使用的GWAS与pQTL数据均为欧洲人群，将结论外推至东亚人群时存在祖先遗传异质性，后续需要东亚人群GWAS数据进一步验证；第二，孟德尔随机化揭示的是遗传层面的因果效应，不等同于药物干预后的效应，遗传扰动与药物干预的时效、幅度存在差异；第三，本研究属于计算机整合分析，仅生成机制假说，缺少细胞、动物实验以及临床队列验证；第四，中介孟德尔随机化检验效能有限，部分真实中介因子可能因效能不足呈现假阴性；第五，网络药理学靶点预测算法本身仍存在一定假阳性，化合物与靶点的结合作用有待分子对接、体外结合实验验证。

综上，本研究为黄芪加味真武汤靶向慢性心力衰竭-虚弱恶性循环提供了具备遗传因果证据支撑的潜在分子机制假说，区分了中介因子与共享上游调控因子两类靶点，为后续机制验证、靶点筛选与复方配伍优化提供候选方向。

### 结论
本研究整合双向孟德尔随机化、顺式pQTL孟德尔随机化联合共定位、中介孟德尔随机化因果分层分析与网络药理学，证实慢性心力衰竭与虚弱存在双向因果效应，支持二者形成恶性循环；筛选得到一批同时对慢性心力衰竭、虚弱存在因果效应的共享蛋白，并划分为中介因子与共享上游调控因子。通过方药靶点交集，识别黄芪加味真武汤可靶向的因果靶点，这些靶点主要富集于炎症调控、心肌重构、氧化应激、能量代谢与衰老相关通路。
本研究区别于传统网络药理学，以遗传因果证据先行锁定疾病靶点，降低靶点假阳性。结果提示黄芪加味真武汤可能通过靶向中介因子和共享上游调控因子，从“阻断表型间因果传递”和“同时抑制两种疾病发病风险”两个层面干预慢性心力衰竭-虚弱恶性循环。
本研究为计算机整合分析，所得机制假说仍需分子对接、细胞动物实验及临床队列进一步验证。

### 📥 1. 表型双向 MR（CHF ↔ Frailty）

**输入**：CHF GWAS（Shah 2020）与 FI GWAS（Atkins 2021, *Aging Cell*）的汇总统计量。**本地存放路径**如 `data/gwas/`，不上传。

```r
#| label: bidirectional-mr
#| warning: false
#| message: false

library(TwoSampleMR)
library(dplyr)

# 1.1 提取工具变量（以 CHF 为暴露为例）
exp_chf <- extract_instruments(outcomes = "ebi-a-GCST009541", # 示例 ID，需替换为实际 Shah 2020 ID
                                p1 = 5e-8, clump = TRUE, r2 = 0.001, kb = 10000)

# 1.2 结局数据提取（FI）
out_fi <- extract_outcome_data(snps = exp_chf$SNP, outcomes = "ieu-b-XX", # 替换为 Atkins FI 的 OpenGWAS ID
                               proxies = FALSE)

# 1.3 Harmonise
dat_fwd <- harmonise_data(exp_chf, out_fi)

# 1.4 正向 MR
```

### 🧪 2. cis-pQTL MR 与共定位（锁定双向因果蛋白）

**输入**：deCODE pQTL（SomaScan v4）与 CHF/FI GWAS 汇总数据。**deCODE 全量文件极大，仅本地读取，不上传**。此处以“遍历蛋白”的循环骨架为例，实际运行时逐蛋白提取 cis 窗口（±500 kb）内的工具变量。

```r
#| label: cis-pqtl-mr
#| eval: false

library(MendelianRandomization)
library(coloc)

# 假设 pqtl_list 为蛋白-基因名向量；pqtl_files 为对应本地路径
pqtl_list <- read.csv("data/pqtl/decode_protein_list.csv")$protein

cis_mr_results <- data.frame()

for (prot in pqtl_list[1:50]) { # 演示前 50 个，实际全量循环
  # 读取该蛋白 cis 区域 pQTL（本地文件，不上传）
  pqtl <- fread(paste0("data/pqtl/decode_cis/", prot, "_cis.tsv"))
  
  # 提取 CHF 结局
  chf_out <- extract_outcome_data(snps = pqtl$SNP, outcomes = "ebi-a-GCST009541")
  # 提取 FI 结局
  fi_out  <- extract_outcome_data(snps = pqtl$SNP, outcomes = "ieu-b-XX")
  
  # 正向 MR：蛋白 → CHF
  dat_chf <- harmonise_data(pqtl, chf_out)
  res_chf <- mr(dat_chf, method_list = c("mr_ivw", "mr_wald_ratio"))
  
  # 正向 MR：蛋白 → FI
  dat_fi <- harmonise_data(pqtl, fi_out)
  res_fi <- mr(dat_fi, method_list = c("mr_ivw", "mr_wald_ratio"))
  
  # 共定位（coloc.abf）——以 CHF 为例
  # 需准备 pqtl 与 GWAS 的 beta/varbeta 列表，此处略去具体窗口提取步骤
  # coloc_res <- coloc.abf(dataset1 = pqtl_list_obj, dataset2 = gwas_list_obj, MAF = 0.1)
  
  cis_mr_results <- bind_rows(cis_mr_results,
    data.frame(protein = prot,
               beta_CHF = res_chf$b[1], se_CHF = res_chf$se[1], p_CHF = res_chf$pval[1],
               beta_FI  = res_fi$b[1],  se_FI  = res_fi$se[1],  p_FI  = res_fi$pval[1]))
}

# 筛选：双结局均显著（FDR < 0.05），后续再叠加反向 MR 与共定位 PP.H4 > 0.7
cis_mr_results$fdr_CHF <- p.adjust(cis_mr_results$p_CHF, method = "BH")
cis_mr_results$fdr_FI  <- p.adjust(cis_mr_results$p_FI,  method = "BH")
candidate_proteins <- subset(cis_mr_results, fdr_CHF < 0.05 & fdr_FI < 0.05)
write.csv(candidate_proteins, "outputs/tables/candidate_causal_proteins.csv", row.names = FALSE)
```

### 🔄 3. 因果分层：两步 MR 与多变量 MR（MVMR）

**目标**：将候选蛋白分为**共享上游、单向中介、双向中介**。核心逻辑：MVMR 中调整一个疾病后，蛋白对另一疾病的直接效应是否仍显著。

```r
#| label: causal-stratification
#| eval: false

library(MVMR)

# 以蛋白 M 为例，输入格式需为 MVMR 要求的 SNP 层面数据
# 数据框需包含：snps, beta.exposure, se.exposure, beta.outcome, se.outcome 等

# 3.1 两步 MR：CHF → M（β1）与 M → Frailty（β2）
# 第一步：CHF 工具变量 → 蛋白 M
chf_iv <- extract_instruments(outcomes = "ebi-a-GCST009541", p1 = 5e-8, clump = TRUE)
m_out <- extract_outcome_data(snps = chf_iv$SNP, outcomes = "pqtl_M_dataset_id")
dat_step1 <- harmonise_data(chf_iv, m_out)
res_step1 <- mr(dat_step1, method_list = "mr_ivw") # β1

# 第二步：蛋白 M 的 cis-pQTL → Frailty
m_iv <- fread("data/pqtl/decode_cis/M_cis.tsv")
fi_out_m <- extract_outcome_data(snps = m_iv$SNP, outcomes = "ieu-b-XX")
dat_step2 <- harmonise_data(m_iv, fi_out_m)
res_step2 <- mr(dat_step2, method_list = "mr_ivw") # β2

# 中介效应 = β1 × β2（需 bootstrap 置信区间，此处仅展示点估计）
indirect_CHF_to_FI <- res_step1$b * res_step2$b

# 3.2 反向两步 MR：Frailty → M（β3）与 M → CHF（β4）
fi_iv <- extract_instruments(outcomes = "ieu-b-XX", p1 = 5e-8, clump = TRUE)
m_out_rev <- extract_outcome_data(snps = fi_iv$SNP, outcomes = "pqtl_M_dataset_id")
dat_step3 <- harmonise_data(fi_iv, m_out_rev)
res_step3 <- mr(dat_step3, method_list = "mr_ivw") # β3

chf_out_m <- extract_outcome_data(snps = m_iv$SNP, outcomes = "ebi-a-GCST009541")
dat_step4 <- harmonise_data(m_iv, chf_out_m)
res_step4 <- mr(dat_step4, method_list = "mr_ivw") # β4

indirect_FI_to_CHF <- res_step3$b * res_step4$b

# 3.3 MVMR：调整 CHF 后，M 对 Frailty 的直接效应
# 构建 MVMR 输入（需合并两个暴露的工具变量到同一 SNP 集）
mvmr_input <- format_mvmr(
  BXGs = cbind(dat_step2$beta.exposure, dat_step1$beta.exposure), # M 与 CHF 对 SNP 的效应
  BYG = dat_step2$beta.outcome, # Frailty
  seBXGs = cbind(dat_step2$se.exposure, dat_step1$se.exposure),
  seBYG = dat_step2$se.outcome,
  RSID = dat_step2$SNP
)
mvmr_res <- ivw_mvmr(mvmr_input)
# mvmr_res 中 M 的直接效应若仍显著 → 支持共享上游；若消失/大幅衰减且间接效应显著 → 支持中介

# 3.4 分类规则（点估计层面）
# 双向中介：indirect_CHF_to_FI 与 indirect_FI_to_CHF 均 > 0 且显著
# 单向中介：仅其中一个间接效应显著，且 MVMR 直接效应衰减
# 共享上游：两个间接效应均不显著，且 MVMR 直接效应仍显著
```

### 📊 5. GEO 验证：limma 差异表达与 GSVA

**数据集**：GSE57338（心衰心肌）与 GSE1428（骨骼肌衰老替代）。**表达矩阵本地存放**，GEOquery 直接下载或读取本地缓存。

```r
#| label: geo-validation
#| message: false
#| warning: false

library(GEOquery)
library(limma)
library(GSVA)
library(pROC)

# 5.1 GSE57338 下载与预处理
gse_hf <- getGEO("GSE57338", GSEMatrix = TRUE, AnnotGPL = TRUE)
expr_hf <- exprs(gse_hf[[1]])
pheno_hf <- pData(gse_hf[[1]])

# 构建分组（需根据实际 pheno 列调整）
group_hf <- ifelse(grepl("heart failure|HF", pheno_hf$title, ignore.case = TRUE), "HF", "Control")
design_hf <- model.matrix(~ 0 + factor(group_hf))
colnames(design_hf) <- c("Control", "HF")
fit_hf <- lmFit(expr_hf, design_hf)
contrast_hf <- makeContrasts(HF - Control, levels = design_hf)
fit2_hf <- eBayes(contrasts.fit(fit_hf, contrast_hf))
deg_hf <- topTable(fit2_hf, number = Inf, adjust.method = "BH")

# 5.2 提取因果交集靶点的差异表达
causal_genes <- read.csv("outputs/tables/drug_causal_intersect.csv")$gene
deg_causal <- deg_hf[rownames(deg_hf) %in% causal_genes, ]
write.csv(deg_causal, "outputs/tables/GSE57338_causal_DEG.csv", row.names = TRUE)

# 5.3 GSVA：以三类因果靶点集为自定义基因集
gene_sets <- list(
  SharedUpstream = read.csv("outputs/tables/causal_upstream.csv")$gene,
  BidirectionalMediator = read.csv("outputs/tables/causal_mediator_bidirectional.csv")$gene,
  UnidirectionalMediator = read.csv("outputs/tables/causal_mediator_uni.csv")$gene
)

gsva_param <- gsvaParam(expr_hf, gene_sets, kcdf = "Gaussian")
gsva_scores <- gsva(gsva_param)

# 5.4 组间比较（Wilcoxon 或 limma）
gsva_res <- data.frame()
for (set_name in rownames(gsva_scores)) {
  scores <- gsva_scores[set_name, ]
  wt <- wilcox.test(scores ~ group_hf)
  gsva_res <- rbind(gsva_res, data.frame(gene_set = set_name, p_value = wt$p.value,
                                          mean_HF = mean(scores[group_hf == "HF"]),
                                          mean_Control = mean(scores[group_hf == "Control"])))
}
write.csv(gsva_res, "outputs/tables/GSVA_causal_sets_GSE57338.csv", row.names = FALSE)

# 5.5 ROC（对 hub 因果基因）
roc_res <- roc(group_hf, expr_hf[intersect(causal_genes, rownames(expr_hf))[1], ])
# 可循环多个基因，导出 AUC 表
```
