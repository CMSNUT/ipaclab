PyMACS：基于 Python 的 GROMACS 分子动力学设置、模拟与分析自动化套件

约 879 字大约 3 分钟

PythonGROMACS分子动力学自动化

2026-11-06

原文地址: PyMACS：把GROMACS手艺活儿搓成“流水线”？

https://pubmed.ncbi.nlm.nih.gov/42241776/

PyMACS 是 2026 年发表在 European Journal of Medicinal Chemistry 上的一篇工具论文[1]，目标是把 GROMACS 的分子动力学（MD）模拟，从结构准备一路自动化到 figurebook 出图。 MD 模拟的难点，集中在跑之前的一长串准备工作——结构清理、拓扑生成、配体参数化、溶剂化……PyMACS 把这一整套流程做成了可复现的工作流工程。本文从架构、核心实现、实战与评估四个角度，对它做一次系统梳理。

  • 使用电磁安全设置进行能量最小化

  • NPT均衡配合GPU加速（如可用）
  • 带GPU加速的生产型MD（如有）

📊 第3A步——分析

conda activate mdanalysis
python 3A_AutomateGromacs.py

典型提示：

Detected ligand candidate: A1D
Use A1D as ligand? [Y/n]: Y
Enter compound display name (or press ENTER to use resname): CPD32
Detected 24 CPU threads available
Enter number of threads to use [ENTER = auto]:

重要的分析模式行为：

  • 如果你在 中选择 PROTAC，脚本会自动切换到3A_AutomateGromacs.py``3_PROTAC_Analysis.py
  • 如果你做配体分析并且存在，可以自动调用它来构建配体相互作用网络图3B_NETWORX.py``3A_AutomateGromacs.py
  • 如果你运行无配体多链蛋白-蛋白/蛋白-肽分析，则 除非使用3A_AutomateGromacs.py``3C_Interface_RIN.py``--skip-interface-rin
  • 如果运行蛋白-肽模式而不使用显性配体，则被视为界面分析，而非配体式的NETWRX
  • 如果你明确地提供，3A保持配体中心的行为--ligand
  • 如果运行单链蛋白分析或生物系统分析，则跳过配体式NETWRX和界面RIN调度
