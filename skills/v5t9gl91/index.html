中药数据库的应用

约 2521 字大约 8 分钟

2026-11-08

TCMSP数据的获取

  • 从tcmsp 2.3网站获取药材的化合物和靶点信息。以下是“药材列表 -> 化合物 -> 靶点”完整获取流程的总结。
  • 缺PubChem CID信息

📊 一、 数据获取的核心逻辑

TCMSP 的网页结构决定了数据是内嵌在 JavaScript 变量中的。因此，核心策略是“抓取网页源码 -> 正则提取 JSON -> 格式化保存”。

数据层级数据内容获取方式与原理
药材列表药材的中文名、拼音、英文名https://old.tcmsp-e.com/browse.php?qc=herbs, 右键，"查看网页源码"，复制$("#grid").kendoGrid({ data: 后面[]中的数据(包括[])，保存为herbs_dict.json 作为本地字典。
化合物信息Mol ID、Molecule Name、OB、DL、MW、AlogP 等针对目标药材，构造 URL 请求网页。利用正则 data:\s*(\[.*?\])\s*,\s*pageSize 提取 #grid 后的 JSON 数组。可以一次性将全部数据下载下来
靶点信息Molecule ID、Molecule Name、Target Name、DrugBank ID 等dataSource: {在同一个药材网页源码中，提取 #grid2 后的第二个 JSON 数组。

💻 二、 R 语言实现的技术流程

整个自动化脚本分为三大步：

1. 字典准备

  • 解决方案：将长文本保存为本地文件 herbs_dict.json，代码中使用 jsonlite::fromJSON() 从文件读取。

2. 核心函数封装（抓取与解析）

  • URL 构造：提取药材的英文名，使用 URLencode() 处理空格（如 Radix Puerariae -> Radix%20Puerariae），拼接 token。
  • 请求头伪装：添加 User-Agent（如 Chrome/120）防止被防火墙拦截。
  • JSON 提取：使用 stringr::str_match_all() 配合 DOTALL 模式 (?s) 跨行提取。
  • 数据校验与保存：使用 jsonlite::validate() 检查提取结果，使用 writeLines() 保存为 .json 文件（如 compounds_fuzi.json）。

3. 批量循环与断点续传

  • 循环队列：从字典中提取所需的药材中文名列表（如“附子、白术、茯苓、白芍、生姜、黄芪”或全量 300+ 味）。
  • 防封禁机制：每次请求后 Sys.sleep(runif(1, 5, 10))，模拟人类操作。
  • 断点续传：在函数开头检查 if (file.exists(...)) return("SKIPPED")，如果中途 Token 过期或网络断开，换新 Token 重跑时，脚本会自动跳过已下载的药材。

⚠️ 三、 关键技术难点与避坑指南

  1. Token 认证频繁过期：
    • TCMSP 属于老旧的 Web 系统，API 的 token 鉴权极易失效。
    • 应对策略：报错 TOKEN_EXPIRED_OR_NO_DATA 时，去浏览器打开 TCMSP 搜索任意药材，按 F12 或 view-source: 在源码中搜索 token=，获取最新字符串替换到代码中。脚本的重试机制（断点续传）确保你不需要从头再跑。
  2. URL 中的特殊字符：
    • 药材的英文名中包含大量空格和特殊符号，必须进行 URL 编码，否则 httr::GET 会报错。
  3. 数据缺失（空结果）：
    • 部分药材在 TCMSP 中没有收录，或者没有达到 OB/DL 阈值的化合物。脚本中必须做好 if (nrow(match_matrix) < 2) 的异常捕获，避免某个药材卡死整个流程。

📁 四、 最终输出结果

运行完毕后，你的 tcmsp_data 目录下会生成结构化的 JSON 文件：

  • compounds_fuzi.json（附子化合物表）
  • targets_fuzi.json（附子靶点表）
  • compounds_huangqi.json（黄芪化合物表）
  • targets_huangqi.json（黄芪靶点表）
  • ...（依此类推）

💡 下一步（数据清洗与整合）

由于输出的是 JSON，在进入后续的网络药理学分析（如 PPI 构建、富集分析）之前，你需要用 R 将其转换为数据框并合并：

# 读取并转换为数据框
fuzi_compounds <- as.data.frame(fromJSON("tcmsp_data/compounds_fuzi.json"))
huangqi_compounds <- as.data.frame(fromJSON("tcmsp_data/compounds_huangqi.json"))

# 合并所有药材的化合物
all_compounds <- rbind(fuzi_compounds, huangqi_compounds)
# 去重（不同药材可能含有同一种化合物）
all_compounds <- all_compounds[!duplicated(all_compounds$MOL_ID), ]

  • 下载的数据无法形成关联数据，因此每个都要在前端浏览器生成的临时内存链接（Blob URL）进行下载

  • 页面下载的药材的靶点中没有对应的化合物信息，要关联化合物-靶点，需到化合物页面下载，好烦

File formats

::::tabs File formats

::: tab herb

The herb info file includes all detail information of the 6,892 herbs. The detail of each column are as follows:

  1. Herb_id: A unique identifier for each herb within the HERD database.

  2. Herb_cn_name: The official Chinese name of the herb.

  3. Herb_alias_name: Various alternative names for the herb in Chinese.

  4. Herb_pinyin_name: The pronunciation of the herb's Chinese name using Pinyin.

  5. Herb_en_name: The common English name of the herb.

  6. Herb_latin_name: The scientific Latin name that classifies the species of the herb.

  7. Properties: A description of the inherent characteristics or 'properties' of the herb, often referring to its nature in Traditional Chinese Medicine (TCM), such as being warm, cold, sweet, pungent, etc.

  8. Meridians: The specific pathways or 'meridians' in the body through which the herb is believed to act, according to TCM theory.

  9. UsePart: The specific part of the herb that is used for medicinal purposes, such as the root, leaf, seed, or bulb.

  10. Function: A description of the medicinal functions or 'effects' the herb is traditionally believed to have.

  11. Indication: The conditions or symptoms for which the herb is traditionally used to treat.

  12. Toxicity: Information regarding the potential toxicity or side effects of the herb.

  13. Clinical_manifestations: The observed clinical effects or indications that the herb may address or alleviate.

  14. Therapeutic_en_class: The therapeutic category of the herb in English, which may include terms like 'blood activation and stasis removal' or 'medicinal for detoxification'.

  15. Therapeutic_cn_class: The therapeutic category of the herb in Chinese, providing a cultural and linguistic context for its use.

  16. TCMID_id: A cross-reference identifier linking the herb to the TCMID database.

  17. TCM_ID_id: A cross-reference identifier for the herb within the TCM-ID database.

  18. SymMap_id: A cross-reference identifier for the herb within the SymMap database.

  20. TCMSP_id: A cross-reference identifier for the herb within the TCMSP database.

::::

::: tab ingredient

The ingredient info file includes all detail information of the 44,595 ingredients. The detail of each column are as follows:

  1. Ingredient_id: A unique identifier for each ingredient within the HERB database.

  2. Ingredient_name: The common name by which the ingredient is widely recognized.

  3. Ingredient_alias_name: A list of alternative names or aliases for the ingredient, separated by semicolons.

  4. Molecular_formula: The chemical formula representing the molecule's composition.

  5. Canonical_smiles: A unique representation of the molecular structure in the SMILES (Simplified Molecular-Input Line-Entry System) format.

  6. Isomeric_smiles: A SMILES string that may differ from the canonical SMILES due to isomerism in the molecule's structure.

  7. InChI: The International Chemical Identifier, a standard identifier for chemical substances, providing a more detailed description than SMILES.

  8. InChIKey: A hashed version of the InChI, used as a compact and web-friendly identifier for the substance.

  9. MolWt: The molecular weight of the ingredient, a measure of the mass of one mole of the substance.

  10. NumHAcceptors: The number of hydrogen bond acceptors in the molecule.

  11. NumHDonors: The number of hydrogen bond donors in the molecule.

  12. MolLogP: The logarithm of the octanol-water partition coefficient, a measure of the molecule's hydrophobicity.

  13. NumRotatableBonds: The number of rotatable bonds in the molecule, which can affect its flexibility and pharmacokinetics.

  14. Drug_likeness: A quantitative measure estimating how closely the ingredient resembles drugs.

  15. OB_score: The Oral Bioavailability score, indicating the likelihood of the substance being absorbed in the gastrointestinal tract when taken orally.

  16. CAS_id: A cross-reference identifier for the ingredient in the Chemical Abstracts Service database.

  17. SymMap_id: A cross-reference identifier linking the ingredient to the SymMap database, which may provide information on the ingredient's effects on biological systems.

  18. TCMID_id: A cross-reference identifier for the ingredient in the TCMID database.

  19. TCMSP_id: A cross-reference identifier for the ingredient in the TCMSP database.

  20. TCM_ID_id: A cross-reference identifier for the ingredient in the TCM-ID database.

  21. PubChem_id: A cross-reference identifier for the ingredient in the PubChem database.

  22. DrugBank_id: A cross-reference identifier for the ingredient in the DrugBank database.

  23. NPASS_id: A cross-reference identifier for the ingredient in the NPASS database.

  24. HIT_id: A cross-reference identifier for the ingredient in the HIT 2.0 database.

:::

::: tab target

The target info file includes all detail information of the 15,515 target genes. The detail of each column are as follows:

  1. Target_id: A unique identifier assigned to each target gene within the HERB database.

  2. Gene_symbol: The official symbol used to represent the gene.

  3. Gene_alias_name: A list of alternative names or aliases for the gene, separated by semicolons.

  4. Protein_name: The name of the protein product encoded by the gene.

  5. Type_of_gene: The classification or type of gene, such as 'protein-coding' and 'ncRNA'.

  6. TTD_target_type: The type of target as categorized in the TTD database, which may include 'Successful target' or 'Discontinued target'.

  7. Organism: The species to which the gene belongs.

  8. Taxonomy_id: The unique identifier for the species in the taxonomic database, often used for referencing in genetic and biological databases.

  9. Map_location: The chromosomal location where the gene is mapped, given as a band or region on the chromosome.

  10. Chromosome: The specific chromosome on which the gene is located.

  11. Entrez_id: The unique identifier for the gene in the Entrez database, a part of the NCBI database collection.

  12. OMIM_id: The identifier for the gene in the Online Mendelian Inheritance in Man (OMIM) database, which is a comprehensive catalog of human genes and genetic disorders.

  13. HGNC_id: The identifier for the gene in the HUGO Gene Nomenclature Committee (HGNC) database, which is responsible for the standardized nomenclature of human genes.

  14. Ensembl_id: The identifier for the gene in the Ensembl database, a genomics database project that provides a centralized resource for genome-scale data from vertebrates and other eukaryotes.

  15. MGI_id: The identifier for the gene in the Mouse Genome Informatics (MGI) database, which is a comprehensive resource for the laboratory mouse genomics and genetics data.

  16. TTD_id: A unique identifier for the target in the Therapeutic Target Database (TTD), which compiles information on targets for therapeutic intervention.

:::

::: tab disease

The disease info file includes all detail information of the 30,170 diseases. The detail of each column are as follows:

  1. Disease_id: The unique identifier for the disease as recorded in the HERB database.

  2. Disease_name: The official or primary name by which the disease is commonly known.

  3. Disease_alias_name: A list of alternative names, synonyms, or aliases for the disease, separated by semicolons.

  4. DisGeNET_disease_type: The type or classification of the disease as categorized in the DisGeNET database.

  5. UMLS_disease_type: The type of disease as classified in the Unified Medical Language System (UMLS), a comprehensive system for biomedical vocabularies.

  6. MeSH_disease_class: The class or category of the disease within the Medical Subject Headings (MeSH), which is used for indexing, cataloging, and searching biomedical literature.

  7. HPO_disease_class: The class or category of the disease within the Human Phenotype Ontology (HPO), which provides a standardized vocabulary for human phenotypic abnormalities.

  8. DO_disease_class: The class or category of the disease within the Disease Ontology (DO), which offers a classification for human diseases.

  9. UMLS_disease_type_id: The identifier for the disease type within the UMLS classification system.

  10. MeSH_disease_class_id: The identifier for the MeSH disease class.

  11. HPO_disease_class_id: The identifier for the HPO disease class.

  12. DO_disease_class_id: The identifier for the DO disease class.

  13. DisGeNET_id: The unique identifier for the disease within the DisGeNET database.

  14. MeSH_id: The cross-reference identifier for the disease within the MeSH database.

  15. HPO_id: The cross-reference identifier for the disease within the HPO database.

  16. DO_id: The cross-reference identifier for the disease within the Disease Ontology database.

  17. ICD10_id: The cross-reference identifier for the disease within the International Classification of Diseases, 10th Revision (ICD-10), which is used for epidemiological purposes and for the clinical coding of diseases.

  18. OMIM_id: The cross-reference identifier for the disease within the Online Mendelian Inheritance in Man (OMIM) database, which focuses on the genetic aspects of human diseases.
